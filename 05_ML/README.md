# Machine Learning

IMU 추가 실험 데이터로 로봇 말단 위치를 예측하기 위한 데이터 전처리, 모델 학습, 평가 자료를 보관하는 폴더입니다.

## 폴더 구성

| 폴더 | 내용 |
|---|---|
| `src/` | 데이터 준비, 학습 및 평가 코드 |
| `configs/` | 데이터 처리와 실험 설정 |
| `tests/` | 코드와 데이터 형식 검사 |
| `docs/` | 실험 설계와 결과 설명 |
| `receipts/` | 실행 및 검증 기록 |
| `artifacts/` | 생성된 중간 산출물 |
| `model_results/` | 학습된 모델과 평가 결과 |
| `tools/` | 보조 실행 도구 |

## 입력 데이터

기본 데이터는 `../03_Dataset_Collection/imu_added_experiment/`에 있습니다. 주요 입력은 IMU와 모터 엔코더 값이며, Vive Tracker 위치는 학습 정답과 평가 기준으로 사용합니다.

## 주요 작업

- 원본 데이터를 ML 입력 형식으로 정리
- 학습·검증 데이터 분리와 데이터 품질 확인
- 말단 위치 회귀 모델 학습 및 평가
- 학습 결과와 모델 파일 저장

세부 실행 방법과 실험 설정은 `docs/`, `configs/`, `pyproject.toml`을 확인합니다.
