# Long-stroke형 카본봉 매니퓰레이터에서 링크별 3점 IMU 배열 기반 형상 재구성 및 End Effector 위치 제어 연구방법론

## 1. 연구 개요

본 연구는 처짐이 발생하는 long-stroke형 카본봉 매니퓰레이터에서, 엔코더 없이도 IMU 배열만으로 링크의 변형 형상을 재구성하고 End effector의 위치를 추정·보정할 수 있는지를 실험적으로 검증하는 연구이다. 연구 대상 로봇은 모터와 카본봉으로 구성된 경량 매니퓰레이터이며, 긴 링크 구조로 인해 카본봉의 탄성 변형, 중력 방향 처짐, 구동 중 진동, 조립 오차, 백래시 등이 End effector의 실제 위치에 영향을 미친다.

일반적인 엔코더 기반 제어는 모터 또는 관절의 회전량을 측정하고, 이를 forward kinematics에 입력하여 End effector 위치를 추정한다. 이 방식은 관절각을 안정적으로 얻을 수 있다는 장점이 있으나, 카본봉을 강체 링크로 가정하는 nominal rigid-body model에 기반한다. 따라서 long-stroke형 구조에서 발생하는 링크 처짐, 휨, 중앙부 변형, 동적 진동은 엔코더 기반 FK에 직접 반영되지 않는다.

본 연구의 핵심은 이러한 한계를 보완하기 위해 각 카본봉 링크에 다중 IMU를 배치하는 것이다. 구체적으로 한 링크당 IMU를 3개 배치한다. IMU는 링크의 시작단과 끝단에 각각 1개씩, 중앙부에 1개를 부착한다. 즉, 하나의 카본봉 링크에 대해 말단 2포인트와 중앙 1포인트의 자세 정보를 동시에 취득한다. 이를 통해 단일 말단 IMU의 가속도 적분으로 위치를 추정하는 것이 아니라, 링크 위 여러 지점의 자세 정보를 이용하여 카본봉의 변형 형상, 곡률, 처짐 방향을 재구성한다.

따라서 본 연구에서 IMU-only 조건은 단순히 “IMU 하나로 위치를 적분하는 방식”이 아니다. 본 연구의 IMU-only 조건은 엔코더 측정값을 제어 피드백으로 사용하지 않고, 링크별 3점 IMU 배열에서 얻은 자세 정보를 기반으로 링크 형상을 재구성하고, 재구성된 링크 형상으로부터 End effector 위치를 계산하는 방식이다. 즉, IMU-only는 엔코더의 대체 가능성을 실험적으로 검증하는 본 연구의 핵심 조건이다.

본 연구의 전체 구도는 다음과 같다.

- Encoder only: 엔코더 기반 nominal rigid-body FK baseline
- IMU array only: 링크별 3점 IMU 배열 기반 형상 재구성 및 위치 추정 제안 방법
- Encoder + IMU fusion: 엔코더 관절각과 IMU 기반 형상 재구성 정보를 결합한 융합 방법
- No correction: 센서 피드백 및 보정이 없는 기준 조건

Tracker는 제어 루프에 포함하지 않고, End effector의 실제 위치와 카본봉 형상 재구성 정확도를 평가하기 위한 ground truth 측정 장치로 사용한다.

## 2. 연구의 핵심 주장

본 연구의 핵심 주장은 다음과 같다.

첫째, long-stroke형 카본봉 매니퓰레이터에서는 엔코더 기반 nominal FK가 실제 End effector 위치를 충분히 설명하지 못할 수 있다. 이는 엔코더가 관절각은 측정하지만 카본봉의 탄성 처짐과 변형 형상을 직접 측정하지 못하기 때문이다.

둘째, 링크별 3점 IMU 배열을 사용하면 각 링크의 시작단, 중앙부, 끝단 자세를 관측할 수 있으므로, 카본봉의 변형 형상을 일정 수준 재구성할 수 있다.

셋째, IMU array 기반 형상 재구성으로 얻은 forward kinematics는 엔코더 기반 nominal FK보다 처짐이 큰 자세에서 End effector 위치를 더 정확히 추정할 가능성이 있다.

넷째, IMU-only 조건은 결함 있는 비교 조건이 아니라, 본 연구의 제안 방법이다. 이 조건은 엔코더 측정값 없이 IMU 배열의 자세 정보만으로 링크 형상을 재구성하고, 이를 기반으로 End effector 위치를 추정한다.

다섯째, IMU 기반 형상 재구성의 정확도는 IMU 등급, 필터링 방식, IMU 간 좌표계 정렬, 장착 강성, 링크의 지배 진동 모드, 목표점 영역에 따라 달라진다.

## 3. 연구 목적

본 연구의 목적은 다음과 같다.

1. long-stroke형 카본봉 매니퓰레이터에서 엔코더 기반 nominal FK의 위치 추정 오차를 정량적으로 분석한다.

2. 링크별 3점 IMU 배열을 이용하여 카본봉의 변형 형상을 재구성하고, 이를 기반으로 End effector 위치를 추정하는 IMU-only 제어 조건을 구현한다.

3. IMU array only 조건이 Encoder only baseline보다 End effector 위치 RMSE를 감소시키는지 검증한다.

4. 저가형 IMU의 raw data, Kalman filter, Madgwick filter 조건을 비교하여 필터링 방식이 형상 재구성 정확도와 위치 제어 정확도에 미치는 영향을 분석한다.

5. 고가형 IMU의 내부 Kalman 기반 출력 조건과 저가형 IMU Kalman 조건을 비교하여 IMU 등급에 따른 성능 차이를 분석한다.

6. Encoder + IMU fusion 조건이 Encoder only와 IMU array only 조건보다 더 안정적인 위치 추정 및 제어 성능을 보이는지 확인한다.

7. 정적 최종 위치 오차뿐 아니라 정착시간, 과도구간 RMS 오차, 잔류 진동 RMS 등 동적 지표를 함께 측정하여 IMU 배열의 동적 피드백 센서로서의 장점을 평가한다.

8. IMU 배열 기반 형상 재구성 정확도 자체를 Tracker를 통해 검증하고, 형상 재구성 정확도와 End effector 위치 제어 성능 사이의 관계를 분석한다.

## 4. 연구 문제

### 연구 문제 1
long-stroke형 카본봉 매니퓰레이터에서 Encoder only 조건은 처짐이 큰 자세에서 systematic bias를 보이는가?

### 연구 문제 2
링크별 3점 IMU 배열 기반 형상 재구성 방식은 엔코더 측정값 없이 End effector 위치를 추정할 수 있는가?

### 연구 문제 3
IMU array only 조건은 Encoder only 조건보다 처짐이 큰 목표점 영역에서 End effector 위치 RMSE를 유의하게 감소시키는가?

### 연구 문제 4
저가형 IMU에서 raw data, Kalman filter, Madgwick filter 조건은 형상 재구성 정확도와 위치 제어 정확도에 서로 다른 영향을 미치는가?

### 연구 문제 5
고가형 IMU Kalman 조건은 저가형 IMU Kalman 조건보다 형상 재구성 RMSE, End effector 위치 RMSE, 잔류 진동 RMS에서 더 우수한 성능을 보이는가?

### 연구 문제 6
Encoder + IMU fusion 조건은 Encoder only 또는 IMU array only 조건보다 전체 작업영역에서 더 안정적인 위치 제어 성능을 보이는가?

### 연구 문제 7
IMU array 기반 형상 재구성 RMSE와 End effector 위치 RMSE 사이에는 양의 상관관계가 존재하는가?

## 5. 연구 가설

### 가설 1
long-stroke형 카본봉 매니퓰레이터에서 엔코더 기반 nominal FK는 링크 처짐으로 인한 systematic bias를 가지며, 이 bias는 reach가 길거나 수평 신장 자세에 가까울수록 증가한다.

### 가설 2
링크별 3점 IMU 자세값을 이용한 형상 재구성 기반 FK는 동일한 제어기와 보정 산식 하에서 엔코더 기반 nominal FK보다 End effector 위치 RMSE를 감소시킬 것이다.

### 가설 3
IMU array 기반 형상 재구성의 효과는 처짐이 큰 자세 영역에서 두드러지고, 처짐이 작은 자세 영역에서는 감소할 것이다.

### 가설 4
저가형 IMU raw data 조건보다 Kalman filter 또는 Madgwick filter를 적용한 조건에서 형상 재구성 RMSE와 End effector 위치 RMSE가 감소할 것이다.

### 가설 5
고가형 IMU Kalman 조건은 저가형 IMU Kalman 조건보다 자세 추정 안정성이 높아 형상 재구성 RMSE와 잔류 진동 RMS를 감소시킬 것이다.

### 가설 6
Encoder + IMU fusion 조건은 엔코더의 관절각 정보와 IMU 배열의 링크 변형 정보를 함께 사용하므로, Encoder only 또는 IMU array only 조건보다 전체 RMSE와 반복 측정 변동성이 작을 것이다.

### 가설 7
IMU array 기반 형상 재구성 RMSE가 작을수록 End effector 위치 RMSE도 작아질 것이다.

## 6. 실험 설계의 기본 원칙

본 연구는 센서별로 서로 다른 제어 알고리즘을 최적화하여 비교하는 연구가 아니다. 제어기, 보정 산식, 제어 gain, 보정 반복 횟수, 보정 종료 기준은 모든 조건에서 동일하게 유지한다. 조건 간 차이는 현재 상태 또는 End effector 위치를 추정하는 센서 정보와 그 센서 정보의 처리 방식에 둔다.

다만 IMU-only 조건은 엔코더 기반 관절각을 사용하지 않기 때문에, Encoder only 조건과 완전히 동일한 상태 추정 파이프라인을 사용할 수는 없다. 따라서 본 연구는 다음 원칙을 적용한다.

1. 제어기에 입력되는 최종 상태량의 형식은 모든 조건에서 동일하게 한다.
2. 각 조건은 최종적으로 End effector 위치 추정값 P_hat 또는 위치 오차 추정값 e_hat을 출력한다.
3. P_hat 또는 e_hat 이후의 보정 산식과 제어기는 동일하게 유지한다.
4. Tracker는 제어에 사용하지 않고, 평가에만 사용한다.
5. IMU-only 조건은 엔코더 값을 사용하지 않고, 링크별 3점 IMU 배열의 자세값만으로 형상을 재구성한다.

즉, 본 연구의 비교는 다음과 같이 정리된다.

- Encoder only: 관절각 기반 rigid-body FK
- IMU array only: 링크 자세 기반 deformed-shape FK
- Encoder + IMU fusion: 관절각 기반 FK와 IMU 기반 변형 형상 정보를 결합한 FK

## 7. 로봇 플랫폼 구조, 링크 길이 조건 및 IMU 배열 구성

본 연구의 실험 플랫폼은 ST3215 모터와 카본봉 링크로 구성된 long-stroke형 경량 매니퓰레이터이다. 로봇은 하부 베이스에서 시작하여 A 링크, B 링크, C 링크로 이어지는 다관절 구조를 가지며, 각 링크는 카본봉으로 구성된다. 본 연구에서는 동일한 구조를 유지하되 링크 길이가 다른 장신형 모델과 단신형 모델을 사용한다.

### 7.1 로봇 플랫폼 모델 구분

| 모델 | A 링크 | B 링크 | C 링크 | 실험적 의미 |
|---|---:|---:|---:|---|
| 장신형 모델 | 233 mm | 215 mm | 106 mm | 긴 작업 반경, 큰 처짐 예상 조건 |
| 단신형 모델 | 183 mm | 165 mm | 56 mm | 짧은 작업 반경, 낮은 처짐 예상 조건 |

장신형과 단신형을 구분하는 이유는 팔 길이에 따른 처짐 효과를 분리하여 분석하기 위함이다. 일반적으로 카본봉 링크가 길어질수록 중력 방향 처짐, 탄성 변형, 진동, 자세 오차에 의한 말단 위치 오차가 증가할 가능성이 크다. 따라서 장신형 모델은 처짐이 크게 발생할 것으로 예상되는 조건이며, 단신형 모델은 상대적으로 처짐이 작을 것으로 예상되는 비교 조건이다.

연구 목표 측면에서 로봇의 작업 반경은 클수록 실제 적용 가능성이 높다. 특히 장신형 모델은 더 넓은 작업영역을 확보할 수 있으므로 사업적·응용적 관점에서 중요하다. 본 연구에서는 장신형 모델에서 처짐이 증가한다는 가정하에, IMU array 기반 형상 재구성이 큰 작업 반경 조건에서도 End effector 위치 추정 및 제어에 효과적인지 검증한다.

### 7.1.1 SO-101 기반 D-H 구조와 유효 링크 길이

본 연구의 로봇 플랫폼은 D-H 파라미터 구조 측면에서 SO-101 로봇과 거의 동일한 운동학적 구성을 따른다. 즉, 관절의 배치, 회전축 방향, 관절 순서, 좌표계 설정 방식은 SO-101의 nominal kinematic structure를 기준으로 사용한다. 다만 본 연구에서는 장신형과 단신형 모델에 따라 모터축 간 링크 길이가 달라진다.

설계도에서 제시된 A, B, C 값은 카본봉 또는 링크 구간의 기준 길이를 의미하며, 실제 forward kinematics와 D-H 파라미터에 반영해야 하는 길이는 각 관절 모터축 사이의 거리이다. 설계도 기준으로 각 링크의 모터축 간 유효 길이는 다음과 같이 정의한다.

- 1번 팔 유효 링크 길이: L_A = A + 66.5 mm
- 2번 팔 유효 링크 길이: L_B = B + 84.5 mm
- 3번 팔 또는 손목 유효 링크 길이: L_C = C + 44.3 mm

따라서 장신형과 단신형의 D-H/FK 입력용 유효 링크 길이는 다음과 같다.

| 모델 | A | B | C | L_A = A+66.5 | L_B = B+84.5 | L_C = C+44.3 |
|---|---:|---:|---:|---:|---:|---:|
| 장신형 | 233 mm | 215 mm | 106 mm | 299.5 mm | 299.5 mm | 150.3 mm |
| 단신형 | 183 mm | 165 mm | 56 mm | 249.5 mm | 249.5 mm | 100.3 mm |

즉, 장신형은 1번 팔과 2번 팔의 모터축 간 거리가 각각 299.5 mm이고, 손목부 유효 길이는 150.3 mm이다. 단신형은 1번 팔과 2번 팔의 모터축 간 거리가 각각 249.5 mm이고, 손목부 유효 길이는 100.3 mm이다.

본 연구에서 Encoder only 조건의 nominal rigid-body FK와 D-H 기반 IK 계산에는 위 유효 링크 길이를 사용한다. 반면 IMU array 기반 형상 재구성에서는 카본봉 위 IMU 부착 위치를 실제 물리적 길이 좌표로 정의해야 하므로, A, B, C로 표현되는 카본봉 구간 길이와 L_A, L_B, L_C로 표현되는 모터축 간 유효 길이를 구분하여 기록한다.

이 구분은 매우 중요하다. 만약 FK 계산에 카본봉 노출 길이 A, B, C를 그대로 사용하면, 모터축 간 거리와 실제 회전 중심 간 거리가 반영되지 않아 nominal FK 자체에 체계적 오차가 생긴다. 따라서 본 연구에서는 SO-101과 동일한 D-H 구조를 사용하되, 장신형/단신형 모델별 유효 링크 길이만 위 표에 따라 변경한다.

### 7.2 장신형/단신형의 변인 역할

장신형과 단신형은 단순한 제작 버전 차이가 아니라, 링크 길이에 따른 처짐 효과를 검증하기 위한 추가 독립변인으로 설정한다.

| 변인 | 수준 | 해석 |
|---|---|---|
| 로봇 길이 조건 | 단신형 / 장신형 | 링크 길이에 따른 처짐 및 제어 오차 변화 분석 |
| 처짐 예상 수준 | 낮음 / 높음 | 단신형은 낮은 처짐 조건, 장신형은 높은 처짐 조건으로 가정 |
| 작업 반경 | 작음 / 큼 | 장신형은 실제 적용 가능성이 높은 넓은 작업영역 조건 |

이에 따라 주요 비교는 다음과 같이 구성한다.

1. 단신형에서 Encoder only와 IMU array only의 성능 비교
2. 장신형에서 Encoder only와 IMU array only의 성능 비교
3. 단신형 대비 장신형에서 처짐 오차가 얼마나 증가하는지 분석
4. 장신형에서 IMU array 기반 형상 재구성의 개선 효과가 더 크게 나타나는지 검증

### 7.3 IMU 센서 모델 구분

본 연구에서는 저가형 IMU 조건과 상위 IMU 조건을 구분한다.

| IMU 구분 | 사용 센서 | 사용 목적 |
|---|---|---|
| 저가형 IMU | MPU6050 | 저비용 IMU array 기반 형상 재구성 가능성 검증 |
| 상위 IMU | WT901C | 내부 자세 출력 및 상대적으로 안정적인 실시간 자세 데이터 기반 비교 조건 |

MPU6050은 저가형 IMU 조건으로 사용하며, raw 가속도 및 각속도 데이터를 수집한 뒤 Raw, Kalman, Madgwick 조건으로 나누어 처리한다. WT901C는 실시간 자세 데이터 수집이 용이한 상위 IMU 조건으로 사용하며, 내부 처리된 자세 출력 또는 Kalman 기반 출력 조건으로 비교한다. 단, WT901C와 MPU6050의 비교는 순수한 센서 칩 성능 비교라기보다 “저가형 raw 기반 IMU array 구성”과 “상위 자세 출력형 IMU array 구성”의 실험적 비교로 해석한다.

### 7.4 IMU 배열 구성

본 연구에서 IMU는 각 카본봉 링크에 대해 3개씩 장착한다.

| IMU 위치 | 역할 |
|---|---|
| 링크 시작단 IMU | 링크 시작부의 절대 자세 및 이전 링크와의 상대 자세 추정 |
| 링크 중앙 IMU | 링크 중앙부의 처짐, 곡률, 진동 모드 추정 |
| 링크 끝단 IMU | 링크 끝부의 자세 및 다음 링크와의 상대 자세 추정 |

각 IMU의 local x축은 카본봉의 길이 방향과 일치하도록 장착한다. local y축과 z축은 링크 단면 방향을 기준으로 통일한다. 모든 IMU의 좌표축은 실험 전 상호 캘리브레이션을 통해 공통 기준 좌표계로 정렬한다.

### 7.5 IMU 좌표계

각 IMU의 자세는 회전행렬 R 또는 quaternion q로 표현한다. i번째 링크의 시작단, 중앙, 끝단 IMU 자세를 각각 다음과 같이 정의한다.

- R_i,0: i번째 링크 시작단 IMU 자세
- R_i,m: i번째 링크 중앙 IMU 자세
- R_i,1: i번째 링크 끝단 IMU 자세

각 지점의 링크 방향 벡터는 IMU local x축을 world frame으로 변환하여 구한다.

u_i,0 = R_i,0 e_x

u_i,m = R_i,m e_x

u_i,1 = R_i,1 e_x

여기서 e_x는 링크 길이 방향을 나타내는 local unit vector이다.

### 7.6 베이스 기준 자세 정의

IMU array 기반 형상 재구성은 첫 번째 링크의 시작점 p_1(0)과 base frame의 자세가 안정적으로 정의되어야 한다. 본 연구의 기본 가정은 베이스가 실험 테이블 또는 지그에 강체적으로 고정되어 있으며, base frame은 실험 중 변하지 않는다는 것이다.

다만 실제 실험에서는 모터 토크 반력, 케이블 장력, 지그 유격 등으로 인해 베이스가 미세하게 움직일 가능성이 있다. 따라서 다음 중 하나의 방법으로 base frame 안정성을 검증한다.

1. 베이스에 기준 IMU를 추가로 부착하여 실험 중 base 자세 변화를 기록한다.
2. Tracker 마커를 베이스에 부착하여 base frame의 위치 및 자세 변화를 측정한다.
3. 실험 전후 base 기준 좌표계가 변하지 않았는지 캘리브레이션 점검을 수행한다.

본 연구의 기본 구현에서는 베이스 강체 고정 가정을 사용하되, base IMU 또는 base Tracker marker를 통해 이 가정을 검증한다. 실험 중 base 자세 변화가 사전 기준값을 초과하면 해당 trial에 base_motion_flag를 부여하고 주 분석에서 제외하거나 별도 민감도 분석에 사용한다.

## 8. IMU array only 조건의 수학적 정의

IMU array only 조건에서는 엔코더 측정값을 사용하지 않는다. 대신 각 링크에 부착된 3점 IMU의 자세값을 이용하여 카본봉의 deformed centerline을 재구성하고, 이를 통해 End effector 위치를 추정한다.

본 연구에서 중요한 점은 IMU array only가 가속도 이중 적분으로 위치를 구하는 방식이 아니라는 점이다. 본 연구는 각 IMU의 자세를 이용하여 링크의 접선 방향장을 구성하고, 이 방향장을 링크의 호 길이 방향으로 적분하여 위치를 계산한다. 따라서 일반적인 strapdown INS 방식의 위치 드리프트 문제와 구별된다.

### 8.1 링크 중심선의 호 길이 보존 정식화

각 링크의 중심선을 호 길이 매개변수 s로 표현한다.

- s ∈ [0, L_i]
- L_i: i번째 카본봉 링크의 실제 길이
- p_i(s): i번째 링크 중심선 상의 위치
- R_i(s): i번째 링크 중심선 상의 자세장
- e_x: IMU local frame에서 카본봉 접선 방향 단위벡터

링크 중심선의 접선 방향은 다음과 같이 정의한다.

u_i(s) = R_i(s)e_x

따라서 링크 끝점 위치는 다음과 같이 계산한다.

p_i(L_i) = p_i(0) + ∫_0^{L_i} u_i(s) ds

이 식은 링크의 직선 거리를 L_i로 고정하는 것이 아니라, 카본봉의 실제 호 길이 L_i를 보존하면서 접선 방향장을 적분하는 방식이다. 카본봉이 휘어질 경우 양끝 사이의 chord length는 L_i보다 작아질 수 있으나, 중심선의 arc length는 L_i로 유지된다.

### 8.2 3점 IMU 기반 자세장 보간

i번째 링크에는 시작단, 중앙, 끝단에 IMU가 부착된다.

- R_i,0: s = 0 위치의 IMU 자세
- R_i,m: s = L_i/2 위치의 IMU 자세
- R_i,1: s = L_i 위치의 IMU 자세

세 자세값을 이용하여 R_i(s)를 보간한다. 자세 보간은 단순한 오일러각 선형 보간이 아니라 quaternion SLERP 또는 SO(3) spline을 사용하는 것을 원칙으로 한다. 이는 자세 보간 과정에서 회전군의 기하학적 일관성을 유지하기 위함이다.

초기 구현에서는 링크를 두 개의 절반 구간으로 나누어 다음과 같이 구성한다.

1. 구간 1: s ∈ [0, L_i/2], R_i,0에서 R_i,m으로 보간
2. 구간 2: s ∈ [L_i/2, L_i], R_i,m에서 R_i,1로 보간

수치 적분은 사다리꼴 적분 또는 Simpson 적분으로 수행한다.

p_i(L_i/2) = p_i(0) + ∫_0^{L_i/2} R_i(s)e_x ds

p_i(L_i) = p_i(L_i/2) + ∫_{L_i/2}^{L_i} R_i(s)e_x ds

이 방식은 기존의 단순식인 normalize(u_i,0 + u_i,m)에 L_i/2를 곱하는 작은 처짐 근사보다 일반적이며, 큰 처짐 조건에서도 arc length 보존 조건을 만족한다.

### 8.3 원호 근사 기반 대안 모델

실시간 계산량을 줄이기 위해 각 절반 링크를 piecewise circular arc로 근사할 수도 있다. 두 IMU 사이의 접선 방향 변화각을 Δθ, 구간 길이를 l = L_i/2라고 하면 곡률은 다음과 같이 근사할 수 있다.

κ = Δθ / l

원호 반경은 다음과 같다.

r = 1 / κ

이때 해당 구간의 chord length는 다음과 같다.

c = 2r sin(Δθ/2)

원호 근사 방식은 정적 처짐 또는 1차 굽힘 모드가 우세한 조건에서 유효하다. 다만 비틀림이나 고차 진동 모드가 크게 포함될 경우 오차가 커질 수 있으므로, 본 연구에서는 arc-length orientation integration을 기본 모델로 두고, piecewise circular arc를 계산량 절감을 위한 비교 모델로 활용할 수 있다.

### 8.4 Raw IMU 조건의 정의

Low-IMU Raw only 조건은 raw data를 아무 변환 없이 위치 계산에 직접 사용하는 조건이 아니다. raw IMU는 가속도와 각속도를 제공하므로, 형상 재구성을 위해서는 최소한의 자세 추정 절차가 필요하다.

본 연구에서 Raw 조건은 다음과 같이 정의한다.

- 초기 정지 상태에서 가속도계를 이용해 roll/pitch를 중력 방향에 정렬한다.
- 이후 각속도 데이터를 시간 적분하여 자세를 갱신한다.
- Kalman filter 또는 Madgwick filter와 같은 확률적·비선형 보정 필터는 사용하지 않는다.
- 정지 구간에서 gyro bias를 보정할 수 있으나, 실시간 상태 보정 필터는 적용하지 않는다.

따라서 Raw 조건은 “필터 없는 gyro-propagated attitude 기반 형상 재구성 조건”으로 정의한다. 이 조건은 필터링이 없는 IMU array의 기준 성능을 평가하기 위한 baseline이다.

### 8.5 비틀림 및 고차 모드에 대한 가정

본 연구의 기본 형상 재구성 모델은 IMU local x축이 카본봉의 국소 접선 방향과 일치한다는 가정에 기반한다. 이는 IMU가 카본봉 표면에 충분히 강체적으로 부착되어 있고, 카본봉의 단면 회전이 해당 지점의 접선 및 자세 변화를 대표한다는 가정이다.

다만 카본봉에 비틀림 모드가 크게 발생하면 IMU의 자세 변화가 순수 굽힘이 아닌 비틀림을 포함하게 된다. 이 경우 굽힘 기반 형상 재구성 모델은 오차를 가질 수 있다. 따라서 본 연구에서는 다음 중 하나를 수행한다.

1. 사전 실험 또는 FEM을 통해 비틀림이 굽힘에 비해 충분히 작음을 확인한다.
2. 비틀림이 무시되지 않는 경우, IMU 자세에서 접선 방향 성분과 비틀림 성분을 분리하는 모델을 추가한다.
3. 비틀림이 큰 자세는 별도 한계 조건으로 분리하여 분석한다.

### 8.6 IMU 자세 오차에 따른 위치 오차 하한

IMU 자세 오차는 링크 길이에 비례하여 위치 오차로 증폭된다. 작은 각도 근사에서 길이 L의 링크에 자세 오차 ε가 있을 때 끝단 위치 오차의 하한은 대략 다음과 같다.

δp ≈ Lε

예를 들어 L = 1 m, ε = 1° = 0.01745 rad이면 δp ≈ 17.5 mm이다. 따라서 본 연구에서는 각 IMU의 정적·동적 자세 정확도와 카본봉 길이를 이용하여 이론적 위치 오차 하한을 사전에 계산하고, 실험 결과의 RMSE와 비교한다.

## 9. Encoder only 조건의 정의

Encoder only 조건은 엔코더 기반 관절각과 nominal rigid-body forward kinematics를 이용하여 End effector 위치를 추정하는 baseline 조건이다.

q_hat_encoder = q_encoder

P_hat_encoder = FK_rigid(q_hat_encoder)

이 조건에서는 카본봉의 처짐, 휨, 탄성 변형, 중앙부 곡률 변화가 FK 모델에 직접 반영되지 않는다. 따라서 Encoder only 조건은 본 연구에서 “처짐을 무시한 관절각 기반 nominal baseline”으로 정의한다.

이 조건은 IMU array only 조건과 대등한 단순 경쟁 조건이라기보다, long-stroke형 구조에서 기존 엔코더 기반 제어가 가지는 한계를 확인하기 위한 기준 조건이다.

## 10. Encoder + IMU fusion 조건의 정의

Encoder + IMU fusion 조건은 엔코더 기반 관절각 정보와 IMU array 기반 형상 재구성 정보를 함께 사용하는 조건이다. 이 조건은 IMU array only와 수학적으로 동일해지지 않도록 명확히 정의해야 한다.

### 10.1 잘못된 fusion 정의의 배제

다음과 같은 정의는 사용하지 않는다.

P_hat_fusion = P_hat_encoder + (P_hat_imu − P_hat_encoder)

이는 전개하면 P_hat_fusion = P_hat_imu가 되어, 실제로는 IMU array only 조건과 동일해진다. 따라서 이러한 방식은 fusion 조건으로 사용할 수 없다.

### 10.2 처짐 잔차 기반 fusion

본 연구에서 fusion의 기본 개념은 엔코더가 제공하는 nominal rigid-body 위치 추정값에 IMU array가 추정한 처짐 잔차를 추가하는 것이다.

P_hat_fusion = P_hat_encoder + delta_hat_deflection

여기서 delta_hat_deflection은 단순히 P_hat_imu − P_hat_encoder로 사후 계산하는 값이 아니다. delta_hat_deflection은 각 링크의 IMU array가 관측한 국소 굽힘, 중앙부 처짐, 접선 방향 변화로부터 계산한 링크별 처짐 증분을 base에서 tip 방향으로 누적한 값이다.

단일 링크 i에 대한 국소 처짐 잔차는 다음과 같이 정의한다.

delta_i = ShapeFK_deformed_i(R_i,0, R_i,m, R_i,1, L_i) − ShapeFK_rigid_i(R_i,0, R_i,1, L_i)

이때 ShapeFK_rigid_i는 동일한 링크의 시작단과 끝단 기준 자세를 사용하되, 중앙부 변형을 반영하지 않는 강체 링크 근사이다. ShapeFK_deformed_i는 시작단, 중앙부, 끝단 IMU 자세를 모두 사용하여 호 길이 보존 방식으로 재구성한 deformed centerline이다.

다링크 매니퓰레이터에서는 링크별 처짐 잔차를 단순히 같은 좌표계에서 더할 수 없다. 각 링크의 처짐 증분은 해당 링크의 local 또는 link frame에서 계산된 뒤, base frame으로 변환하여 순차적으로 누적해야 한다.

따라서 전체 처짐 잔차는 다음과 같이 정의한다.

delta_hat_deflection = Σ_i T_base_to_i · delta_i

여기서 T_base_to_i는 i번째 링크 좌표계에서 계산된 처짐 증분을 base frame으로 변환하는 변환행렬이다. 이 변환은 엔코더 기반 nominal FK 또는 fusion 내부 상태를 기준으로 계산한다.

즉, fusion 조건의 실제 계산 흐름은 다음과 같다.

1. ST3215 엔코더 값으로 q_encoder를 계산한다.
2. SO-101 기반 nominal FK로 각 링크의 base-to-link 변환 T_base_to_i를 계산한다.
3. 각 링크의 3점 IMU 자세로부터 링크별 국소 처짐 증분 delta_i를 계산한다.
4. 각 delta_i를 base frame으로 변환한다.
5. 모든 링크의 처짐 증분을 base-to-tip 순서로 누적한다.
6. P_hat_encoder에 누적 처짐 잔차 delta_hat_deflection을 더해 P_hat_fusion을 계산한다.

이 정의를 사용하면 fusion 조건은 IMU array only와 동일해지지 않는다. Encoder는 nominal 관절 구조와 base-to-link 변환을 제공하고, IMU array는 nominal model에서 빠진 링크별 처짐 잔차를 제공한다.

### 10.3 공분산 기반 fusion

보다 엄밀한 방식으로는 엔코더 기반 위치 추정값과 IMU 기반 위치 추정값의 오차 공분산을 이용하여 fusion을 수행한다.

P_hat_fusion = P_hat_encoder + K_f (P_hat_imu − P_hat_encoder)

여기서 K_f는 스칼라 가중치가 아니라 3×3 행렬 gain으로 정의한다.

K_f = Σ_encoder (Σ_encoder + Σ_imu)^−1

또는 동등한 Kalman update 형태로 구성할 수 있다. 이때 Σ_encoder는 엔코더 기반 FK의 오차 공분산, Σ_imu는 IMU array 기반 형상 재구성 오차 공분산이다.

스칼라 가중평균은 모든 방향의 오차가 동일하다는 isotropic noise 가정을 포함하므로, 본 연구에서는 가능하면 공분산 행렬 기반 fusion을 사용한다. 예를 들어 엔코더는 중력 방향 처짐에 약하고, IMU는 yaw 방향 드리프트에 약할 수 있으므로 방향별 신뢰도를 다르게 부여하는 것이 타당하다.

### 10.4 Fusion 파라미터 결정 원칙

Fusion gain 또는 공분산은 평가 데이터를 보고 사후 조정하지 않는다. 다음 절차 중 하나를 통해 사전에 결정한다.

1. 별도 캘리브레이션 데이터셋에서 엔코더 FK 오차와 IMU ShapeFK 오차를 추정한다.
2. 엔코더 분해능, 백래시, 링크 처짐 모델, IMU 자세 오차 하한을 이용하여 이론적 공분산을 구성한다.
3. pilot data를 통해 공분산을 추정하되, 본 실험 평가 데이터와 분리한다.

## 12. 추가 독립변인: 로봇 길이 조건과 목표점 영역

본 연구의 주제가 long-stroke 처짐이므로 링크 길이는 중요한 실험 요인이다. 본 연구에서는 장신형 모델과 단신형 모델을 사용하여 링크 길이에 따른 처짐 효과를 분리한다.

| 로봇 길이 조건 | A 링크 | B 링크 | C 링크 | D-H/FK 유효 링크 길이 | 처짐 가정 |
|---|---:|---:|---:|---|---|
| 단신형 | 183 mm | 165 mm | 56 mm | L_A=249.5 mm, L_B=249.5 mm, L_C=100.3 mm | 상대적으로 낮은 처짐 |
| 장신형 | 233 mm | 215 mm | 106 mm | L_A=299.5 mm, L_B=299.5 mm, L_C=150.3 mm | 상대적으로 높은 처짐 |

장신형은 단신형보다 A, B, C 링크가 모두 길며, D-H/FK에 들어가는 모터축 간 유효 링크 길이도 증가한다. 따라서 장신형 조건에서는 중력 방향 처짐, 링크 탄성 변형, 진동, 자세 추정 오차의 말단 증폭이 더 크게 나타날 것으로 예상한다.

### 12.1 로봇 길이 조건의 분석 목적

장신형/단신형 비교는 다음 목적을 가진다.

1. 링크 길이가 증가할 때 Encoder only 조건의 위치 오차가 증가하는지 확인한다.
2. 장신형에서 IMU array only 조건의 개선 효과가 단신형보다 크게 나타나는지 확인한다.
3. 작업 반경 확대가 위치 제어 성능과 처짐 보정 필요성에 미치는 영향을 분석한다.
4. 넓은 작업영역을 요구하는 실제 응용 관점에서 장신형 모델의 사업적 타당성을 검토한다.

### 12.2 목표점 영역 층화

장신형과 단신형 각각에 대해 목표점은 처짐 예상 수준에 따라 층화한다.

| 목표점 영역 | 설명 |
|---|---|
| A 영역 | 짧은 reach, 처짐이 작을 것으로 예상되는 영역 |
| B 영역 | 중간 reach, 중간 처짐 예상 영역 |
| C 영역 | 최대 reach 또는 수평 신장, 처짐이 클 것으로 예상되는 영역 |

각 영역에서 동일한 수의 목표점을 무작위 표집한다. 이를 통해 IMU array 기반 형상 재구성의 효과가 링크 길이와 목표점 영역에 따라 어떻게 달라지는지 분석한다.

### 12.3 주요 상호작용 효과

본 연구에서는 센서 조건뿐 아니라 로봇 길이 조건과의 상호작용도 중요하다.

| 상호작용 | 연구적 의미 |
|---|---|
| 센서 조건 × 로봇 길이 | 장신형에서 IMU array 효과가 더 커지는지 확인 |
| 센서 조건 × 목표점 영역 | 처짐이 큰 자세에서 IMU array가 더 유리한지 확인 |
| 로봇 길이 × 목표점 영역 | 긴 링크와 최대 reach 조건이 결합될 때 오차가 증폭되는지 확인 |
| 센서 조건 × 로봇 길이 × 목표점 영역 | 가장 처짐이 큰 조건에서 제안 방법의 효과 검증 |

본 연구의 종속변인은 크게 세 범주로 나눈다.

## 13.1 End effector 위치 제어 성능

| 종속변인 | 정의 |
|---|---|
| 최종 오차 벡터 E | 목표점 P_d와 Tracker 기반 실제점 P′ 사이의 3차원 위치 차이 |
| 오차 크기 | 오차 벡터의 유클리드 거리 |
| 조건별 RMSE | 반복 실험에서 산출한 평균 제곱근 오차 |
| 축별 오차 | Δx, Δy, Δz 각 방향의 오차 성분 |
| 중력 방향 오차 | 처짐과 관련성이 큰 방향의 오차 성분 |
| bias 성분 | 반복 측정에서 평균적으로 나타나는 체계적 오차 |
| random 성분 | bias 제거 후 남는 랜덤 오차 |

오차 벡터는 다음과 같이 정의한다.

E = P_d − P′ = (Δx, Δy, Δz)

오차 크기는 다음과 같이 정의한다.

|E| = sqrt((Δx)^2 + (Δy)^2 + (Δz)^2)

조건별 RMSE는 다음과 같이 계산한다.

RMSE = sqrt((1/n) × sum(|E_i|^2))

## 13.2 형상 재구성 정확도

IMU array의 핵심 주장은 링크 형상을 재구성할 수 있다는 것이므로, End effector 위치 오차뿐 아니라 형상 재구성 정확도 자체를 측정한다.

| 종속변인 | 정의 |
|---|---|
| 링크 지점 재구성 오차 | IMU가 재구성한 링크 시작·중앙·끝 지점 위치와 Tracker 측정값의 차이 |
| 링크 형상 RMSE | 링크 여러 지점에서의 재구성 오차 RMSE |
| 중앙부 처짐 추정 오차 | 카본봉 중앙부의 실제 처짐과 IMU 기반 추정 처짐의 차이 |
| 곡률 추정 오차 | IMU 기반 곡률 또는 굽힘 방향 추정값과 기준 측정값의 차이 |

형상 재구성 RMSE는 다음과 같이 정의할 수 있다.

Shape RMSE = sqrt((1/m) × sum(|p_j,tracker − p_j,imu|^2))

여기서 m은 Tracker로 검증하는 링크 상의 측정 지점 수이다.

## 13.3 동적 응답 성능

IMU는 동적 거동 측정에 강점을 가지므로, 정적 최종 위치 오차만 측정하면 IMU의 장점을 충분히 평가하기 어렵다. 따라서 다음 지표를 추가한다.

| 종속변인 | 정의 |
|---|---|
| 정착시간 | 명령 후 위치 오차가 허용 범위 안에 들어가 유지될 때까지 걸린 시간 |
| 과도구간 RMS 추적오차 | 이동 및 보정 과정에서 발생한 시간 구간별 위치 오차 RMS |
| 잔류 진동 RMS | 정지 후 일정 시간 동안 남아 있는 진동 크기 |
| 최대 오버슈트 | 목표점 주변에서 발생한 최대 위치 초과량 |
| 감쇠 시간 | 잔류 진동이 기준 이하로 감소하는 데 걸린 시간 |

## 14. 공통 제어 및 보정 구조

각 조건은 최종적으로 위치 추정값 P_hat 또는 오차 추정값 e_hat을 출력한다. 이후에는 동일한 보정 산식과 제어기를 사용한다.

e_hat = P_d − P_hat

Δq = J# e_hat

q_cmd,new = q_cmd,old + K Δq

여기서 J#는 자코비안 의사역행렬 또는 damped least squares inverse이며, K는 모든 조건에서 동일하게 설정한 보정 gain이다.

### 14.1 IMU-only 조건에서 q_hat_imu의 의미

IMU-only 조건에서는 엔코더 측정값을 사용하지 않는다. 따라서 자코비안 평가에 필요한 관절 상태 q는 엔코더 값이 아니라 IMU array로부터 추정한 deformed configuration의 effective joint angle로 정의한다.

인접 링크의 IMU 자세로부터 상대 회전을 계산한다.

R_rel,i = R_i,end^T R_i+1,start

이 상대 회전을 해당 관절축에 투영하여 effective joint angle을 추정한다.

q_hat_imu,i = projection_axis(R_rel,i)

여기서 q_hat_imu는 엔코더가 측정하는 명목 관절각과 완전히 동일한 물리량이 아니다. q_hat_imu는 링크 처짐과 끝단 접선 방향 변화를 포함한 deformed configuration의 유효 관절각이다. 따라서 본 연구에서는 q_hat_imu를 “엔코더 대체 관절각”이 아니라 “변형 형상 기반 effective joint coordinate”로 정의한다.

### 14.1.1 자코비안 계산 방식의 실험 구현 결정

실제 제어 실험에서는 실시간성과 조건 간 공정성을 위해 1차 구현에서 SO-101 기반 nominal rigid-body Jacobian을 사용한다. 단, 자코비안의 평가점은 조건별 상태 추정값에 따라 달라진다.

- Encoder only: J_rigid(q_encoder)
- IMU array only: J_rigid(q_hat_imu)
- Encoder + IMU fusion: J_rigid(q_fusion) 또는 J_rigid(q_encoder)

즉, IMU array only에서 사용하는 자코비안은 deformed centerline을 완전히 미분한 자코비안이 아니라, IMU array로 추정한 effective joint coordinate q_hat_imu에서 평가한 nominal rigid Jacobian이다. 이 선택은 제어기 구조를 모든 조건에서 동일하게 유지하고, 실시간 구현을 단순화하기 위한 것이다.

다만 분석 단계에서는 별도로 deformed ShapeFK의 수치 자코비안을 계산하여 nominal Jacobian 기반 보정과 비교할 수 있다.

J_shape(q_hat_imu) ≈ ∂ShapeFK(q_hat_imu) / ∂q

따라서 본 연구에서는 다음과 같이 구분한다.

| 자코비안 | 사용 목적 |
|---|---|
| J_rigid(q_ref) | 실제 제어 실험의 기본 자코비안 |
| J_shape(q_hat_imu) | 사후 분석 또는 확장 실험용 deformed model 자코비안 |

이 구분을 통해 실제 제어 실험에서는 공정하고 구현 가능한 보정 구조를 유지하고, 분석 단계에서는 deformed model을 사용했을 때의 잠재적 개선 가능성을 추가로 평가한다.

### 14.2 자코비안 평가점

각 조건별 자코비안 평가점은 다음과 같이 정의한다.

| 조건 | 자코비안 평가점 |
|---|---|
| Encoder only | q_encoder |
| IMU array only | q_hat_imu |
| Encoder + IMU fusion | 기본 구현에서는 q_encoder, 확장 구현에서는 fused q_hat |
| No correction | 보정 없음 |

Fusion 조건의 기본 구현에서는 안정성과 재현성을 위해 J_rigid(q_encoder)를 사용한다. 이는 fusion에서 엔코더가 nominal 관절 구조를 제공하고, IMU가 링크별 처짐 잔차를 제공하는 역할 분리를 명확히 하기 위함이다. 다만 확장 구현에서 fused q_hat을 사용하는 경우, 엔코더 관절각과 IMU effective joint angle의 공분산 기반 융합값을 사용한다. 이 융합 방식은 실험 전에 고정해야 한다.

### 14.3 Task-space correction 대안

만약 q_hat_imu의 안정성이 충분하지 않거나, effective joint angle을 정의하기 어려운 구조라면 task-space correction을 대안으로 사용할 수 있다. 이 경우 IMU array로 추정한 End effector 위치 오차 e_hat을 직접 task-space correction에 사용한다.

Δq = J(q_ref)^T (J(q_ref)J(q_ref)^T + λI)^−1 e_hat

여기서 q_ref는 다음 중 하나로 사전에 정의한다.

1. 현재 명령 관절값 q_cmd
2. IMU array 기반 effective joint angle q_hat_imu
3. 이전 보정 단계에서 사용한 내부 상태 추정값 q_internal

λ는 damped least squares의 damping coefficient이며, 모든 조건에서 동일하게 적용한다.

### 14.4 보정 종료 기준

보정 종료는 Tracker 기준이 아니라 각 조건의 자기 추정 오차 e_hat 기준으로 판정한다. 단, 종료 후 Tracker로 실제 오차를 측정하여 자기 추정 수렴과 실제 수렴의 차이를 분석한다.

보정 종료 조건은 다음 중 먼저 만족하는 것으로 정의한다.

1. |e_hat| ≤ ε_control
2. 최대 보정 횟수 N_max 도달

각 trial마다 종료 사유를 기록한다.

## 15. Tracker의 역할

Tracker는 제어 피드백에 사용하지 않는다. Tracker는 다음 목적으로만 사용한다.

| Tracker 사용 목적 | 사용 여부 |
|---|---|
| End effector 실제 위치 P′ 측정 | 사용 |
| 링크 지점 위치 측정 | 사용 |
| 형상 재구성 정확도 평가 | 사용 |
| RMSE 계산 | 사용 |
| 동적 추적오차 기준값 확보 | 사용 |
| 실시간 제어 피드백 | 사용하지 않음 |

즉, 로봇은 해당 조건의 센서 정보만을 사용하여 제어되고, Tracker는 사후 평가 기준으로만 사용한다.

## 16. 실험 절차

### 16.1 사전 캘리브레이션

실험 전 다음 절차를 수행한다.

1. IMU 간 좌표계 정렬
2. IMU local x축과 카본봉 접선 방향 정렬 확인
3. IMU bias 측정
4. IMU 케이스 좌표계와 Tracker 마커 좌표계 사이의 hand-eye calibration
5. 자력계 사용 시 자기장 간섭 평가
6. Kalman filter Q, R 튜닝
7. Madgwick filter beta 튜닝
8. Tracker 좌표계 캘리브레이션
9. 엔코더 영점 설정
10. IMU, 제어기, Tracker 데이터의 시간 동기화 확인
11. IMU 부착 전후 카본봉 자유진동 주파수 비교

필터 튜닝은 평가 데이터와 분리된 사전 캘리브레이션 데이터셋에서 수행한다. 평가 결과를 보고 필터 파라미터를 사후 조정하지 않는다.

### 16.2 IMU-마커 좌표계 캘리브레이션

형상 재구성 RMSE를 계산하려면 Tracker가 측정하는 마커 좌표계와 IMU가 출력하는 자세 좌표계 사이의 관계가 명확해야 한다. 따라서 각 IMU에 부착된 Tracker 마커의 좌표계와 IMU local frame 사이의 고정 변환을 사전에 추정한다.

T_marker_to_imu = constant transform

이 변환이 정확하지 않으면 형상 재구성 RMSE가 실제 IMU 재구성 오차가 아니라 마커 장착 오차를 포함하게 된다. 따라서 IMU-마커 hand-eye calibration은 본 실험의 필수 절차로 포함한다.

### 16.3 목표점 설정

작업영역을 처짐 예상 수준에 따라 층화한다. 각 층에서 동일한 수의 목표점을 무작위로 선택한다.

예시:

- 낮은 처짐 영역: 베이스에 가까운 목표점 또는 수직 정렬 자세
- 중간 처짐 영역: 중간 reach 목표점
- 높은 처짐 영역: 수평 최대 신장 또는 긴 reach 목표점

### 16.4 사전 modal test

동적 지표를 분석하기 전에 카본봉의 dominant bending frequency를 측정한다. 방법은 자유진동 실험, impulse hammer test, 또는 일정 변위 후 release test를 사용할 수 있다.

측정된 dominant frequency f_d에 대해 Tracker와 IMU의 샘플링 주파수는 최소 Nyquist 기준을 만족해야 하며, 동적 응답 분석을 위해 가능하면 다음 조건을 만족하도록 한다.

f_sample ≥ 4 f_d

Tracker 샘플링 주파수가 충분하지 않은 경우, 동적 지표는 독립 가속도계 또는 IMU 시계열을 보조적으로 사용하되, 자기 평가 문제가 발생할 수 있으므로 해석상 주의점을 명시한다.

### 16.5 초기 이동

각 목표점 P_d에 대해 IK를 계산하고, feedforward 명령으로 로봇을 목표점 방향으로 이동시킨다. C0 조건은 여기서 보정을 수행하지 않고 최종 위치를 측정한다.

### 16.6 조건별 상태 추정

각 조건에 따라 P_hat을 추정한다.

- C1: 엔코더 기반 FK로 P_hat_encoder 계산
- C2~C5: IMU 배열 기반 형상 재구성으로 P_hat_imu 계산
- C6~C8: 엔코더 기반 FK와 IMU 기반 형상 재구성 정보를 융합하여 P_hat_fusion 계산

### 16.7 공통 보정 수행

추정된 P_hat을 이용해 e_hat을 계산하고, 동일한 보정 산식과 동일한 제어기를 사용하여 보정 명령을 생성한다.

### 16.8 종료 기준

보정 종료 기준은 두 가지를 모두 기록한다.

1. 자기 추정 기준: 각 조건의 e_hat이 임계값 이하가 되었는지
2. 최대 보정 횟수 기준: 사전에 정한 최대 보정 횟수에 도달했는지

Tracker 기준 실제 오차는 종료 판정에 사용하지 않고, 평가 데이터로만 기록한다. 이를 통해 자기 추정으로는 수렴했지만 실제 위치는 맞지 않는 사례를 확인할 수 있다.

### 16.9 최종 측정

정지 후 일정 안정화 시간을 둔 뒤 Tracker로 End effector 위치와 링크 지점 위치를 측정한다. 또한 정착시간, 잔류 진동 RMS, 과도구간 RMS 오차를 계산하기 위해 이동 전 과정의 시계열 데이터를 저장한다.

## 17. 실험 순서 무작위화

조건 수행 순서는 무작위화한다. 항상 같은 순서로 실험하면 모터 온도 상승, 배터리 전압 변화, IMU 드리프트, 반복 구동에 따른 기계적 변화가 특정 조건에 집중될 수 있다.

가능하다면 Williams design 또는 Latin square를 사용하여 1차 carryover effect를 균형화한다. 각 조건 사이에는 washout 절차를 둔다.

Washout 절차 예시:

1. 홈 위치 복귀
2. N초간 정지
3. IMU bias 재확인
4. 필요 시 IMU 자세 초기화
5. Tracker 마커 가시성 확인

## 19. 자료 분석 방법

## 19.1 위치 오차 분석

각 조건별로 최종 위치 오차 벡터와 RMSE를 계산한다. 또한 bias 성분과 random 성분을 분리한다.

bias = mean(E_i)

random_i = E_i − bias

bias가 크다면 특정 조건에서 체계적 오차가 존재함을 의미한다. Encoder only 조건에서 수평 최대 reach 자세의 bias가 중력 방향으로 크게 나타난다면, 이는 처짐을 무시한 nominal FK의 한계로 해석할 수 있다.

## 19.2 형상 재구성 정확도 분석

Tracker로 측정한 링크 지점 위치와 IMU array로 재구성한 링크 지점 위치를 비교한다.

Shape RMSE = sqrt((1/m) × sum(|p_j,tracker − p_j,imu|^2))

이때 Shape RMSE는 두 종류로 분리하여 보고한다.

### 19.2.1 IMU 부착점 RMSE

IMU가 실제로 부착된 시작단, 중앙부, 끝단 위치에서의 재구성 오차를 계산한다. 이 값은 IMU 자세 추정과 IMU-마커 캘리브레이션의 정확도를 반영한다.

### 19.2.2 보간점 RMSE

IMU가 부착되지 않은 IMU 사이의 추가 지점에 Tracker 마커를 부착하여 재구성 오차를 계산한다. 예를 들어 링크당 5~7개 지점을 측정한다.

- IMU 부착점 3개
- IMU 사이 보간 검증점 2~4개

보간점 RMSE는 형상 재구성 모델 자체가 IMU 사이 구간의 곡률과 처짐을 얼마나 잘 예측하는지 평가하는 핵심 지표이다. 본 연구에서는 보간점 RMSE를 형상 재구성 모델 검증의 주 지표로 사용한다.

## 19.3 동적 응답 분석

정착시간, 과도구간 RMS 오차, 잔류 진동 RMS, 최대 오버슈트를 조건별로 비교한다. IMU array 조건이 동적 진동을 더 잘 반영한다면, 정적 최종 오차뿐 아니라 정착시간과 잔류 진동에서도 개선이 나타날 수 있다.

동적 분석은 Tracker 샘플링 주파수가 dominant bending frequency를 충분히 포착할 수 있을 때 수행한다. 샘플링이 부족한 경우 정적 지표와 분리하여 해석한다.

## 19.4 자기 추정 수렴과 실제 수렴의 불일치 분석

각 조건에서 제어기는 자기 추정 오차 e_hat을 기준으로 수렴 여부를 판단한다. 그러나 실제 위치 오차는 Tracker로만 확인할 수 있다. 따라서 다음 네 가지 경우를 구분한다.

| 자기 추정 기준 | Tracker 실제 기준 | 해석 |
|---|---|---|
| 수렴 | 수렴 | 정상 수렴 |
| 수렴 | 비수렴 | 자기 추정은 맞지만 실제 위치는 틀린 경우 |
| 비수렴 | 수렴 | 보수적 추정 또는 센서 과대오차 |
| 비수렴 | 비수렴 | 실제 제어 실패 |

특히 “자기 추정 수렴, Tracker 비수렴” 사례는 IMU array 또는 엔코더 추정 모델의 한계를 보여주는 중요한 결과이므로 별도로 분석한다.

## 19.5 MPU6050 필터 효과 분석

MPU6050 조건 내에서 다음 비교를 수행한다.

- MPU6050 Raw only vs MPU6050 Kalman only
- MPU6050 Raw only vs MPU6050 Madgwick only
- MPU6050 Kalman only vs MPU6050 Madgwick only

이 비교는 동일한 저가형 IMU 하드웨어에서 신호처리 방식만 달라지는 구조이므로 필터링 방식의 영향을 평가하기에 적절하다.

## 19.6 MPU6050 기반 조건과 WT901C 자세 출력 조건 비교

MPU6050 Kalman only와 WT901C attitude only를 비교한다. 단, WT901C의 내부 자세 출력 알고리즘이 MPU6050에 외부 적용한 Kalman filter와 완전히 동일하다고 볼 수 없으므로, 이 비교는 순수한 센서 칩 성능 비교가 아니라 “MPU6050 기반 외부 필터링 IMU array 구성”과 “WT901C 기반 자세 출력형 IMU array 구성”의 실험적 비교로 해석한다.

## 19.7 Encoder baseline과 IMU array 제안 방법 비교

Encoder only와 IMU array only 조건을 비교한다. 전체 작업영역뿐 아니라 처짐 예상 수준별로 나누어 분석한다.

- 낮은 처짐 영역
- 중간 처짐 영역
- 높은 처짐 영역

IMU array 조건의 개선 효과가 높은 처짐 영역에서 더 크게 나타나는지 확인한다.

## 19.8 Fusion 효과 분석

Encoder only, IMU array only, Encoder + IMU fusion 조건을 비교한다. Fusion 조건의 목적은 엔코더의 관절각 안정성과 IMU의 링크 변형 정보를 결합했을 때 위치 추정과 제어가 더 안정화되는지 확인하는 것이다.

## 19.9 변동성 분석

각 조건의 반복 측정 변동성을 분석한다. 변동성 지표는 다음을 사용한다.

- 표준편차
- IQR
- coefficient of variation
- trial-to-trial repeatability error

Fusion 조건이 단일 센서 조건보다 평균 RMSE뿐 아니라 반복 측정 변동성도 낮추는지 확인한다.

## 19.10 형상 재구성 RMSE와 위치 RMSE의 관계 분석

형상 재구성 RMSE와 End effector 위치 RMSE의 관계는 두 단계로 분석한다.

1. 조건 간 분석: 여러 IMU 조건 중 Shape RMSE가 낮은 조건이 End effector RMSE도 낮은지 확인한다.
2. 조건 내 분석: 동일 조건 내에서 목표점 또는 자세별 Shape RMSE와 End effector RMSE가 양의 상관을 보이는지 확인한다.

조건 내 분석은 형상 재구성 정확도가 실제 위치 제어 성능 향상의 기전인지 확인하는 데 중요하다.

## 20. 통계 분석 계획

반복측정 구조를 고려하여 동일 목표점, 동일 카본봉 길이, 동일 자세에서 조건별 결과를 paired data로 분석한다.

### 20.1 표본 수 및 반복 횟수

목표점 수, 반복 횟수, 조건 수는 사전 검정력 분석을 통해 결정하는 것을 원칙으로 한다. 사전 검정력 분석이 어렵다면 파일럿 실험을 통해 조건별 표준편차를 추정하고, 최소 검출 효과크기를 설정한 뒤 본 실험의 n을 결정한다.

### 20.2 검정 방법

자료가 정규성을 만족하면 반복측정 ANOVA 또는 linear mixed-effects model을 사용한다. 목표점, 카본봉 길이, 자세 영역은 random effect 또는 block factor로 설정할 수 있다.

정규성 가정이 만족되지 않으면 Friedman test와 Wilcoxon signed-rank test를 사용한다.

### 20.3 다중비교 보정

조건 간 다중비교에는 Holm 또는 Bonferroni 보정을 적용한다.

### 20.4 효과크기와 신뢰구간

p-value만 제시하지 않고 효과크기와 95% 신뢰구간을 함께 보고한다.

- paired comparison: Cohen's dz 또는 rank-biserial correlation
- ANOVA: partial eta squared
- mixed model: 추정 평균 차이와 95% CI

### 20.5 상관 및 회귀 분석

형상 재구성 RMSE와 End effector 위치 RMSE 사이의 관계는 단순 Pearson 또는 Spearman 상관만으로 판단하지 않는다. 반복측정 구조와 목표점 차이를 고려하기 위해 mixed-effects regression을 함께 사용한다.

예시 모델은 다음과 같다.

EE_RMSE ~ Shape_RMSE + condition + robot_model + posture_region + (1 | target_id)

필요한 경우 조건별 기울기 차이를 보기 위해 다음 모델을 사용할 수 있다.

EE_RMSE ~ Shape_RMSE * condition + (1 | target_id)

이를 통해 형상 재구성 오차가 실제 End effector 위치 오차를 설명하는지, 그리고 그 관계가 센서 조건에 따라 달라지는지 분석한다.

### 20.6 자기 추정 수렴과 실제 수렴의 통계 분석

19.4에서 정의한 네 가지 수렴 사례의 비율을 조건별로 계산한다. 조건 간 수렴/비수렴 비율 차이는 paired binary data 구조를 고려하여 McNemar test, Cochran's Q test, 또는 generalized linear mixed model을 사용한다.

특히 “자기 추정 기준 수렴, Tracker 기준 비수렴” 비율은 각 센서 조건의 자기 상태 추정 신뢰도를 평가하는 핵심 지표로 사용한다.

## 21. 통제 전략

## 21.1 제어기와 보정 산식 통제

모든 조건에서 제어기, 보정 산식, 제어 gain, 보정 반복 횟수, 보정 종료 기준을 동일하게 유지한다.

## 21.2 목표점 층화

목표점은 처짐 예상 수준에 따라 층화하여 표집한다. 이를 통해 IMU array의 장점이 나타날 것으로 예상되는 영역과 그렇지 않은 영역을 모두 포함한다.

## 21.3 카본봉 길이 통제 및 확장

가능하면 2~3개의 카본봉 길이를 포함한다. 단일 길이만 사용하는 경우에는 해당 길이에서 사전 처짐량을 측정하고 연구 범위를 명확히 제한한다.

## 21.4 IMU 캘리브레이션

IMU 간 좌표계 정렬, bias 보정, 장착 오차 보정, 자력계 사용 여부를 명확히 한다. IMU 부착 오차는 systematic bias의 주요 원인이므로 반드시 사전 캘리브레이션을 수행한다.

## 21.5 필터 튜닝 공정성

Kalman filter와 Madgwick filter는 동일한 사전 캘리브레이션 데이터셋을 사용하여 튜닝한다. 한쪽 필터만 최적화하고 다른 필터는 기본값으로 두지 않는다.

## 21.6 데이터 동기화

IMU, 엔코더, 제어기, Tracker 데이터는 동일한 시간 기준으로 동기화한다. 가능하면 하드웨어 트리거를 사용하고, 그렇지 않은 경우 소프트웨어 timestamp와 지연 보정 절차를 명시한다.

## 21.7 환경 통제

전원 전압, 모터 온도, 환경 온도·습도, Tracker 마커 가시성, 케이블 장력, IMU 장착 강성을 기록하고 가능한 일정하게 유지한다.

## 22. IMU array 접근의 한계 및 해석상 주의점

첫째, 링크당 3개 IMU는 연속적인 카본봉 곡률 분포를 유한한 지점에서 샘플링하는 방식이다. 따라서 정적 처짐 또는 1차 굽힘 모드가 지배적인 상황에서는 유효할 수 있으나, 고차 진동 모드가 우세한 경우에는 형상 재구성 정확도가 낮아질 수 있다.

둘째, IMU 자세 오차는 링크 길이에 비례하여 위치 오차로 증폭된다. 예를 들어 1 m 링크에서 1도 자세 오차는 약 17.5 mm 수준의 끝단 위치 오차를 유발할 수 있다. 따라서 IMU 자세 정확도와 링크 길이를 바탕으로 이론적 위치 오차 하한을 사전에 추정해야 한다.

셋째, 자력계를 사용하지 않는 경우 yaw 관측성이 제한될 수 있다. 특히 본 연구의 저가형 IMU인 MPU6050은 자력계를 포함하지 않으므로 yaw drift가 누적될 수 있다. 따라서 MPU6050 조건에서는 각 trial 시작 시 yaw를 초기화하고, trial 시간을 가능한 한 짧게 유지하며, yaw drift 추정값을 별도로 기록한다. 또한 수평면 yaw 오차가 End effector 위치 오차에 크게 영향을 주는 자세와 주로 중력 방향 처짐이 지배적인 자세를 구분하여 해석한다. WT901C 조건에서 자력계 또는 내부 heading 보정이 사용되는 경우에는 모터 자기장과 주변 환경의 자기장 간섭을 평가해야 한다.

넷째, IMU 장착 오차와 좌표축 오정렬은 형상 재구성의 systematic bias를 유발한다. 따라서 IMU 간 상호 캘리브레이션이 필수적이다.

다섯째, 본 연구의 IMU-only는 가속도 이중 적분 기반 위치 추정이 아니라 자세 기반 형상 재구성이다. 따라서 일반적인 strapdown INS의 위치 드리프트 문제와 동일하게 해석해서는 안 된다. 다만 자세 추정 드리프트와 yaw drift는 여전히 성능에 영향을 줄 수 있다.

여섯째, 본 연구 결과는 사용한 카본봉 길이, IMU 장착 위치, 필터링 방식, 목표점 영역, 제어 주기, Tracker 정확도에 의존한다. 따라서 다른 매니퓰레이터 구조로 일반화하려면 추가 검증이 필요하다.

## 24. 추가 개선 설계

이 섹션은 본 연구의 완성도를 높이기 위해 추가적으로 반영할 개선 사항을 정리한다.

### 24.1 단계적 검증 프로토콜

본 실험을 바로 전체 로봇 제어 실험으로 시작하면 오차 원인을 분리하기 어렵다. 따라서 다음 순서의 단계적 검증을 수행한다.

1. 단일 카본봉 정적 처짐 검증
2. 단일 카본봉 동적 진동 검증
3. 1자유도 또는 단일 링크 매니퓰레이터 검증
4. 다자유도 매니퓰레이터 전체 실험

단일 카본봉 검증에서는 알려진 하중을 가하고 Tracker로 실제 형상을 측정한 뒤, IMU array 기반 형상 재구성 결과와 비교한다. 이 단계에서 형상 재구성 모델의 기본 타당성을 확인한다.

각 단계에는 다음 단계로 넘어가기 위한 gate criterion을 둔다.

| 단계 | 통과 기준 예시 |
|---|---|
| 단일 카본봉 정적 처짐 | 보간점 Shape RMSE가 IMU 자세 오차 기반 이론 하한의 2~3배 이내 |
| 단일 카본봉 동적 진동 | dominant frequency에서 위상 오차와 진폭 오차가 사전 기준 이내 |
| 단일 링크 매니퓰레이터 | IMU array only 조건의 EE RMSE가 C0보다 낮고, 자기 추정-Tracker 비수렴 비율이 기준 이하 |
| 다자유도 전체 실험 | 위 단계 통과 후 수행 |

구체적인 수치 기준은 파일럿 실험 결과와 Tracker 정확도를 고려하여 사전에 확정한다.

### 24.2 모델 오차와 센서 오차의 분리

실험 결과가 나빠졌을 때 그 원인이 IMU 센서 오차인지, 형상 재구성 모델 오차인지, 제어기 오차인지 구분할 수 있어야 한다. 이를 위해 다음 세 가지 오차를 분리하여 보고한다.

1. 센서 자세 추정 오차
2. 형상 재구성 모델 오차
3. 제어 적용 후 최종 위치 오차

이 구조를 사용하면 “IMU가 나쁘다”가 아니라 “IMU 자세는 좋지만 보간 모델이 부족하다” 또는 “형상 추정은 좋지만 제어 적용에서 오차가 생긴다”처럼 원인을 구체적으로 해석할 수 있다.

### 24.3 작은 처짐 조건과 큰 처짐 조건의 모델 분리

작은 처짐 조건에서는 piecewise linear 또는 원호 근사가 충분할 수 있다. 그러나 큰 처짐 조건에서는 arc-length preserving integration 또는 spline 기반 모델이 필요할 수 있다. 따라서 본 연구에서는 처짐 각도 또는 링크 중앙 처짐량 기준으로 모델 적용 범위를 나눈다.

예시:

- 작은 처짐: 접선 방향 변화각이 5도 이하
- 중간 처짐: 5도 초과 15도 이하
- 큰 처짐: 15도 초과

구체 기준은 파일럿 실험 결과를 바탕으로 정한다.

### 24.4 실패 사례 분석

IMU array only 조건이 Encoder only보다 항상 우수하다고 가정하지 않는다. 실패 사례를 별도로 분석하는 것이 연구 가치를 높인다.

주요 실패 사례:

- yaw drift로 인한 수평면 위치 오차 증가
- IMU 간 시간 동기화 실패
- IMU 부착 강성 부족으로 카본봉 표면 움직임을 정확히 추종하지 못한 경우
- 고차 진동 모드로 인해 3점 IMU 배열이 형상을 충분히 샘플링하지 못한 경우
- 자기 추정 기준으로는 수렴했으나 Tracker 기준으로는 비수렴한 경우

이러한 실패 사례는 IMU array 방식의 적용 범위와 한계를 규정하는 중요한 결과로 보고한다.

### 24.5 실시간성 평가

IMU array 기반 형상 재구성은 계산량이 증가할 수 있다. 따라서 위치 정확도뿐 아니라 실시간 적용 가능성도 평가한다.

측정 항목:

- IMU 데이터 수집 지연
- 자세 추정 필터 계산 시간
- ShapeFK 계산 시간
- 보정 명령 생성 시간
- 전체 제어 루프 지연

실시간 제어에 사용하려면 전체 loop latency가 제어 주기보다 충분히 작아야 한다.

### 24.5.1 실험 규모 산정 가이드라인

전체 조건을 모두 조합하면 trial 수가 과도하게 증가할 수 있다. 따라서 본 연구에서는 단계별로 조건 수를 줄여 실험한다.

예시 trial 구성은 다음과 같다.

| 단계 | 조건 | 로봇 모델 | 목표점 영역 | 반복 수 | 예상 trial 수 |
|---|---|---|---|---:|---:|
| 1차 | C2, C3, C4 | 단신형 또는 단일 링크 | 3영역 | 5회 | 45 |
| 2차 | C1, Best MPU6050, C5 | 단신형 | 3영역 | 5회 | 45 |
| 3차 | C1, Best IMU, Fusion | 단신형 | 3영역 | 5회 | 45 |
| 4차 | C1, Best IMU, Fusion | 단신형/장신형 | 3영역 | 5회 | 90 |

이 표는 최소 수행량의 예시이며, 파일럿 실험에서 추정한 분산과 가용 실험 시간에 따라 조정한다. 모든 조건을 한 번에 수행하기보다, 1차 실험에서 Best IMU 조건을 먼저 선정한 뒤 이후 비교 조건을 줄이는 방식으로 실험 부담을 관리한다.

### 24.6 센서 배치 최적화 가능성

본 연구에서는 링크당 3개 IMU를 기본 구성으로 사용하지만, 향후에는 IMU 개수와 배치 위치가 성능에 미치는 영향을 분석할 수 있다.

확장 조건:

- 링크당 1개 IMU
- 링크당 2개 IMU
- 링크당 3개 IMU
- 중앙부 밀집 배치
- 끝단부 밀집 배치

이를 통해 최소 센서 개수로 충분한 형상 재구성 성능을 얻을 수 있는지 평가할 수 있다.

### 24.7 실제 적용 관점의 평가 지표

논문적 정확도 외에도 실제 로봇 적용 관점의 지표를 추가할 수 있다.

- 센서 총 비용
- 배선 복잡도
- 캘리브레이션 소요 시간
- 실시간 계산량
- 반복 실험 간 재현성
- 부착 및 유지보수 난이도

이는 저가형 IMU array 방식이 고가형 IMU 또는 엔코더 기반 방식에 비해 실용적 가치가 있는지를 판단하는 데 도움이 된다.

## 25. 실제 실험 수행을 위한 데이터 수집 및 동기화 가이드라인

본 연구는 다중 IMU array, 엔코더, 제어 명령, Tracker 데이터를 함께 사용하므로, 모든 데이터가 동일한 시간축 위에서 해석될 수 있어야 한다. 특히 ST3215 모터는 UART 통신을 통해 모터 상태 및 엔코더 값을 받을 수 있고, 저가형 IMU인 MPU6050은 raw 가속도·각속도 데이터를, WT901C는 실시간 자세·각속도·가속도 데이터를 수집할 수 있다. 그러나 각 장치의 통신 주기, 내부 처리 지연, 수신 시점, 제어 루프 주기가 서로 다를 수 있으므로, 실험 데이터 수집 단계에서 시간 동기화 절차를 명확히 정의해야 한다.

본 연구에서는 모든 센서와 제어 데이터에 대해 타임스탬프를 부여하고, 수집 지연 및 장치 간 시간 오프셋을 보정한 뒤, 동일한 기준 시간축으로 재정렬한다. 또한 향후 지도학습 기반 오차 예측 또는 보정 모델을 구성할 경우, 단순히 센서값만 사용하는 것이 아니라 각 데이터의 수집 지연시간과 동기화 보정량을 별도 feature로 저장한다.

### 25.1 수집 대상 데이터

실험 중 수집해야 하는 데이터는 다음과 같다.

| 데이터 종류 | 주요 항목 | 예시 |
|---|---|---|
| 제어 명령 데이터 | 명령 입력 시각, 목표 관절값, 목표 위치, 보정량 | q_cmd, P_d, Δq |
| ST3215 모터 데이터 | 모터 ID, 엔코더 값, 현재 위치, 속도, 전류, 온도 | q_encoder, motor velocity |
| MPU6050 raw data | 저가형 IMU의 가속도, 각속도 | a_x, a_y, a_z, gyro_x, gyro_y, gyro_z |
| MPU6050 자세 추정 데이터 | raw 적분, Kalman, Madgwick 적용 후 자세 | R_raw, R_kalman, R_madgwick |
| WT901C 데이터 | 실시간 자세, 각속도, 가속도 출력 | roll, pitch, yaw, gyro, acc |
| 필터 출력 데이터 | Kalman 또는 Madgwick 적용 후 자세 | R_kalman, R_madgwick |
| Tracker 데이터 | End effector 위치, 링크 검증점 위치 | P′, p_j,tracker |
| 시스템 시간 데이터 | 수신 시각, 처리 시각, 루프 번호 | timestamp, loop_index |
| 지연시간 데이터 | 센서별 수집 지연, 통신 지연, 보정된 offset | latency_sensor, offset_corrected |

각 데이터는 가능한 한 원본 raw data와 처리 후 data를 모두 저장한다. 예를 들어 IMU의 경우 raw 가속도·각속도, 필터링된 자세값, 최종 형상 재구성에 사용된 자세값을 각각 분리하여 저장한다.

### 25.2 타임스탬프 부여 원칙

모든 데이터에는 공통 기준 시간축에 대한 타임스탬프를 부여한다. 타임스탬프는 단순히 데이터가 파일에 저장된 시각이 아니라, 가능한 한 “해당 데이터가 실제로 측정된 시각”을 근사해야 한다.

타임스탬프는 다음 세 수준으로 나누어 기록한다.

| 타임스탬프 종류 | 의미 |
|---|---|
| t_request | PC 또는 제어기에서 센서 데이터 요청을 보낸 시각 |
| t_receive | 센서 데이터가 PC 또는 제어기에 수신된 시각 |
| t_estimated_sample | 실제 센서 샘플링 시각으로 추정한 값 |

일반적인 경우 센서의 실제 샘플링 시각을 직접 알기 어렵기 때문에, t_request와 t_receive의 중간값을 1차 추정값으로 사용할 수 있다.

t_estimated_sample = (t_request + t_receive) / 2

단, 센서 내부 처리 지연이나 UART 통신 지연이 일정하게 존재하는 경우, 사전 측정된 지연시간을 반영하여 다음과 같이 보정한다.

t_corrected = t_estimated_sample − latency_sensor

여기서 latency_sensor는 해당 센서 또는 통신 경로의 평균 지연시간이다.

### 25.3 샘플링 주기 기반 타임스탬프 보정

각 센서는 서로 다른 주기로 데이터를 출력할 수 있다. 따라서 실험 전 각 장치의 실제 샘플링 주기를 측정하고, 명목 샘플링 주기와 실제 샘플링 주기 사이의 차이를 확인한다.

센서 k의 명목 샘플링 주기를 T_k라고 하면, i번째 샘플의 이상적인 시간은 다음과 같이 정의할 수 있다.

t_k,i = t_k,0 + iT_k

하지만 실제 수신 시각은 통신 지연, OS scheduling, UART buffer, 제어 루프 부하에 따라 불규칙할 수 있다. 따라서 실제 수신 시각 t_receive와 이상적 샘플링 시각 t_k,i를 비교하여 jitter를 계산한다.

jitter_k,i = t_receive,k,i − t_k,i

jitter가 허용 범위보다 크거나 특정 구간에서 누적된다면, 해당 trial은 별도 flag를 부여하거나 분석에서 제외할 수 있다.

### 25.4 센서 간 시간 오프셋 보정

ST3215 엔코더 데이터, WT901C IMU 데이터, Tracker 데이터는 서로 다른 통신 경로와 처리 지연을 가진다. 따라서 각 센서 데이터는 공통 기준 시간축으로 정렬해야 한다.

기준 시간축은 제어 루프의 시작 시각 t0로 정의한다.

t_common = t − t0

각 센서 데이터는 다음과 같이 보정한다.

t_aligned,k = t_corrected,k − offset_k

여기서 offset_k는 기준 시간축에 대한 k번째 센서의 시간 오프셋이다.

오프셋은 다음 방법으로 추정할 수 있다.

1. 동일한 이벤트를 모든 센서가 감지할 수 있도록 실험 시작 시 동기화 이벤트를 발생시킨다.
2. 예를 들어 로봇을 짧게 움직여 엔코더 변화와 IMU 각속도 변화가 동시에 발생하도록 한다.
3. 엔코더 속도 변화 시점과 IMU 각속도 변화 시점을 cross-correlation으로 비교한다.
4. 두 신호의 상관이 최대가 되는 시간차를 offset으로 추정한다.

예:

offset_encoder_imu = argmax_tau corr(velocity_encoder(t), gyro_imu(t + tau))

이 방식은 단순히 저장 시각을 맞추는 것보다 실제 물리적 이벤트 기준으로 센서 간 오프셋을 보정할 수 있다는 장점이 있다.

### 25.5 추가 지연시간 보정

센서 데이터에는 일정한 평균 지연뿐 아니라 상황에 따라 달라지는 추가 지연이 포함될 수 있다. 예를 들어 UART 통신량 증가, 다중 IMU 동시 수신, 파일 저장 부하, 제어 루프 연산량 증가로 인해 일부 구간에서 데이터 수집이 늦어질 수 있다.

따라서 각 데이터에는 다음 값을 함께 저장한다.

| 지연 관련 항목 | 설명 |
|---|---|
| latency_mean | 해당 센서의 평균 수집 지연 |
| latency_std | 지연시간의 표준편차 |
| jitter | 샘플별 수신 시각 변동 |
| dropped_sample_flag | 샘플 누락 여부 |
| delayed_sample_flag | 허용 지연시간 초과 여부 |
| offset_corrected | 보정에 사용된 시간 offset |

지도학습 모델을 구성할 경우, 지연시간 자체도 하나의 입력 feature로 사용할 수 있다. 이는 모델이 센서값의 시간적 불일치가 오차에 미치는 영향을 학습할 수 있도록 하기 위함이다.

예를 들어 학습 데이터에는 다음 항목을 포함한다.

- encoder_latency
- imu_latency
- tracker_latency
- encoder_imu_offset
- imu_tracker_offset
- sampling_jitter
- dropped_sample_flag
- delayed_sample_flag

이러한 지연 관련 feature는 센서 데이터의 품질을 설명하는 보조 변수로 사용된다.

### 25.6 데이터 리샘플링 및 보간

센서별 샘플링 주기가 다르면, 모든 데이터를 동일한 시간축으로 리샘플링해야 한다. 기준 시간축은 제어 루프 주기 또는 가장 낮은 신뢰성 있는 공통 주기로 설정한다.

예를 들어 제어 루프 주기가 10 ms라면, 모든 데이터를 100 Hz 기준 시간축으로 정렬할 수 있다.

리샘플링 방법은 데이터 종류에 따라 다르게 적용한다.

| 데이터 종류 | 보간 방법 |
|---|---|
| 엔코더 위치 | 선형 보간 또는 zero-order hold |
| 엔코더 속도 | 선형 보간 |
| IMU 가속도 | 선형 보간 |
| IMU 각속도 | 선형 보간 |
| IMU 자세 quaternion | SLERP 보간 |
| Tracker 위치 | 선형 보간 또는 smoothing spline |
| 제어 명령 | zero-order hold |

특히 IMU 자세값이 quaternion으로 저장되는 경우, 오일러각을 단순 선형 보간하지 않고 SLERP를 사용한다.

### 25.7 실시간성 검증 기준

본 연구에서는 데이터 수집 시스템의 실시간성을 다음 기준으로 검증한다.

| 항목 | 검증 기준 |
|---|---|
| 평균 샘플링 주기 | 명목 샘플링 주기와의 차이가 허용 범위 이내 |
| 최대 jitter | 제어 주기의 일정 비율 이하 |
| dropped sample 비율 | 사전 설정한 기준 이하 |
| 센서 간 offset | 보정 후 허용 범위 이내 |
| 전체 loop latency | 제어 주기보다 충분히 작음 |

예를 들어 제어 주기가 10 ms라면, 센서 간 동기화 오차는 가능하면 1 ms 내외로 유지하는 것을 목표로 한다. 만약 이 수준의 동기화가 어렵다면, 동적 지표 분석 범위를 축소하고 정적 위치 오차 분석 중심으로 결과를 해석한다.

### 25.8 Trial 품질 관리 기준

각 trial은 데이터 품질 기준을 통과해야 분석에 포함한다. 다음 조건에 해당하는 trial은 별도 flag를 부여하고, 주 분석에서 제외하거나 민감도 분석에만 사용한다.

- 센서 데이터 누락 발생
- IMU 하나 이상에서 timestamp gap 발생
- 엔코더 데이터 수신 지연 과다
- Tracker 마커 가림 발생
- 센서 간 offset 보정 실패
- 제어 루프 주기 초과
- IMU yaw drift 급증
- 전원 전압 급락
- 모터 온도 급상승

제외 기준은 실험 후 임의로 정하지 않고, 실험 전에 사전 정의한다.

### 25.9 실제 실험 로그 저장 형식

각 trial의 데이터는 다음과 같은 구조로 저장한다.

| 필드 | 설명 |
|---|---|
| trial_id | 실험 번호 |
| condition_id | C0~C8 조건 번호 |
| target_id | 목표점 번호 |
| rod_length_id | 카본봉 길이 조건 |
| posture_region | 처짐 예상 영역 |
| loop_index | 제어 루프 index |
| t_common | 공통 기준 시간 |

### 25.10 후속 지도학습 연구를 위한 데이터셋 구성 원칙

본 연구의 주 분석은 실험 기반 위치 오차 및 형상 재구성 성능 비교이다. 다만 후속 연구에서 지도학습 기반 오차 예측 모델을 구성할 수 있도록, 실험 데이터는 다음과 같은 feature와 target 구조로 저장한다.

#### 입력 feature 예시

- 목표점 P_d
- 명령 관절값 q_cmd
- 엔코더 값 q_encoder
- IMU raw data
- IMU 필터링 자세값
- IMU array 기반 형상 feature
- 카본봉 길이
- 목표점 영역
- 이동 속도
- 제어 주기
- 보정 횟수
- 센서별 latency
- 센서 간 offset
- sampling jitter
- dropped sample flag
- delayed sample flag

#### target 예시

- Tracker 기준 실제 오차 E_actual
- End effector 최종 위치 오차 크기 |E|
- 축별 오차 Δx, Δy, Δz
- 형상 재구성 오차
- 보정 전후 오차 변화량

학습 데이터 구성 시 중요한 점은, Tracker로 측정한 실제 오차는 모델 학습의 target 또는 평가 기준으로 사용해야 하며, 실시간 제어 입력으로는 사용하지 않아야 한다는 점이다.

### 25.11 실험 수행 순서 요약

실제 실험은 다음 순서로 수행한다.

1. 장비 전원 및 통신 연결 확인
2. ST3215 모터 UART 통신 확인
3. MPU6050 raw data 수신 확인
4. WT901C 자세 데이터 수신 확인
5. Tracker 좌표계 캘리브레이션
6. IMU-마커 좌표계 캘리브레이션
7. IMU bias 및 자세 초기화
8. 센서별 샘플링 주기 측정
9. 센서 간 offset 측정
10. 동기화 이벤트 수행
11. 로봇 모델 조건 선택: 단신형 또는 장신형
12. 목표점 및 조건 설정
13. feedforward 이동 수행
14. 조건별 상태 추정 및 보정 수행
15. Tracker 기반 실제 위치 측정
16. 데이터 품질 flag 확인
17. trial 데이터 저장
18. 다음 조건 수행 전 washout 절차 수행

### 25.12 데이터 수집 실시간성에 대한 연구계획서 문장

본 연구에서는 ST3215 모터의 UART 기반 엔코더 데이터, MPU6050 raw IMU 데이터, WT901C 자세 데이터를 실시간으로 수집하고, 각 데이터에 공통 기준 시간축 기반 타임스탬프를 부여한다. 센서별 샘플링 주기와 실제 수신 시각을 함께 기록하여 jitter와 dropped sample 여부를 확인하며, 엔코더·IMU·Tracker 데이터 사이의 시간 오프셋은 동기화 이벤트 및 cross-correlation 기반 방법으로 보정한다. 또한 UART 통신 지연, 센서 내부 처리 지연, 데이터 저장 지연 등으로 인해 발생할 수 있는 추가 latency를 별도로 측정하고, 이를 분석 데이터와 지도학습용 feature로 저장한다. 이를 통해 센서값의 시간적 불일치가 위치 추정 및 보정 성능에 미치는 영향을 정량적으로 관리한다.

## 26. 실험 운영 및 협업 구현 가이드라인

본 연구는 모터 제어, 다중 IMU 수집, Tracker 측정, 형상 재구성, fusion, 통계 분석이 결합된 복합 실험이다. 따라서 실험자가 바뀌거나 코드 담당자가 바뀌더라도 동일한 데이터 구조와 동일한 좌표계, 동일한 캘리브레이션 파일을 사용할 수 있도록 운영 기준을 사전에 고정해야 한다. 본 섹션은 실제 실험 수행과 코드 구현을 위한 협업 가이드라인을 정의한다.

### 26.1 역할 분담 매트릭스

실험 수행 전 각 모듈의 담당자를 명확히 지정한다. 담당자는 단순 구현자가 아니라 해당 모듈의 입력, 출력, 단위, 좌표계, 데이터 저장 형식까지 책임지는 사람으로 정의한다.

| 모듈 | 주요 역할 | 입력 | 출력 | 담당자 |
|---|---|---|---|---|
| ST3215 통신 모듈 | UART 기반 모터 명령 전송 및 엔코더 수신 | q_cmd, motor_id, baudrate | q_encoder, motor_velocity, motor_temperature, t_encoder | 담당자 지정 |
| MPU6050 펌웨어/수집 모듈 | raw 가속도·각속도 수집 | imu_id, i2c_address, sampling_rate | acc_raw, gyro_raw, t_imu | 담당자 지정 |
| MPU6050 자세 추정 모듈 | raw 적분, Kalman, Madgwick 자세 추정 | acc_raw, gyro_raw, calibration_imu | R_raw, R_kalman, R_madgwick | 담당자 지정 |
| WT901C 통신 모듈 | WT901C 자세·가속도·각속도 수신 | sensor_id, serial_port, baudrate | R_wt901c, acc_wt901c, gyro_wt901c, t_wt901c | 담당자 지정 |
| Tracker 통신 모듈 | End effector 및 링크 마커 좌표 수집 | marker_id, tracker_config | P_actual_base, p_marker_world, t_tracker | 담당자 지정 |
| 시간 동기화 모듈 | 센서 간 offset, latency, jitter 보정 | t_encoder, t_imu, t_tracker, sync_event | t_common, offset_table, latency_features | 담당자 지정 |
| ShapeFK 모듈 | IMU array 기반 링크 형상 재구성 | R_i_0_world, R_i_m_world, R_i_1_world, L_i, calibration_shape | p_i_end_base, delta_i_link, shape_points_base | 담당자 지정 |
| Rigid FK/IK 모듈 | SO-101 기반 nominal FK/IK 계산 | q_encoder, q_cmd, dh_params | P_hat_encoder_base, J_rigid, q_ik | 담당자 지정 |
| Fusion 모듈 | 엔코더 FK와 IMU 처짐 잔차 융합 | P_hat_encoder_base, delta_i_link, T_base_to_i, covariance_config | P_hat_fusion_base, delta_hat_deflection_base | 담당자 지정 |
| 제어 보정 모듈 | 공통 보정 산식 및 명령 생성 | P_d_base, P_hat_base, J_ref, K, epsilon_control | e_hat_base, delta_q, q_cmd_new | 담당자 지정 |
| 데이터 로깅 모듈 | raw/processed/analyzed 데이터 저장 | all module outputs | trial files, metadata, quality_flags | 담당자 지정 |
| 통계 분석 모듈 | RMSE, mixed model, 다중비교, 시각화 | analysis_dataset | tables, plots, statistical_report | 담당자 지정 |

각 담당자는 코드 함수명, 입력 변수명, 출력 변수명, 좌표계, 단위를 문서화해야 한다. 모듈 간 입출력 형식이 바뀌면 관련 담당자 전원이 확인한 뒤 버전을 갱신한다.

### 26.3 좌표계 약속 및 변수 명명 규칙

본 연구에서는 base frame, world frame, link frame, IMU frame, marker frame이 동시에 사용된다. 따라서 모든 위치, 자세, 벡터 변수에는 frame suffix를 강제한다.

### 26.3.1 기본 좌표계 정의

| 좌표계 | 표기 | 의미 |
|---|---|---|
| world frame | world | Tracker 또는 실험실 기준 전역 좌표계 |
| base frame | base | 로봇 베이스 기준 좌표계 |
| link frame | link_i | i번째 링크 기준 좌표계 |
| IMU frame | imu_i_pos | 각 IMU의 local sensor frame |
| marker frame | marker_i | Tracker 마커 기준 좌표계 |
| motor frame | motor_i | ST3215 모터축 기준 좌표계 |

### 26.3.2 변수명 규칙

모든 변수는 다음 형식을 따른다.

- 위치: p_or_P_description_frame
- 자세: R_from_to 또는 q_from_to
- 오차: e_description_frame
- 처짐 잔차: delta_description_frame
- 시간: t_source_corrected

예시는 다음과 같다.

| 변수명 | 의미 |
|---|---|
| P_d_base | 목표점 P_d를 base frame에서 표현한 값 |
| P_actual_base | Tracker로 측정한 실제 End effector 위치를 base frame으로 변환한 값 |
| P_hat_encoder_base | 엔코더 기반 FK 위치 추정값 |
| P_hat_imu_base | IMU array 기반 ShapeFK 위치 추정값 |
| P_hat_fusion_base | fusion 기반 위치 추정값 |
| R_i_m_world | i번째 링크 중앙 IMU 자세를 world frame 기준으로 표현한 값 |
| R_world_to_base | world frame에서 base frame으로의 회전 |
| delta_i_link | i번째 링크의 local frame 기준 처짐 잔차 |
| delta_hat_deflection_base | 전체 링크 처짐 잔차를 base frame에서 누적한 값 |
| e_hat_base | 제어기에 입력되는 추정 위치 오차 |
| E_actual_base | Tracker 기준 실제 위치 오차 |
| q_encoder_rad | ST3215 엔코더 기반 관절각 |
| q_hat_imu_rad | IMU array 기반 effective joint coordinate |

frame suffix가 없는 위치·자세 변수는 코드 리뷰에서 허용하지 않는다. 예를 들어 P_hat, delta_i, R_i와 같은 변수명은 분석용 노트가 아닌 실제 코드에서는 사용하지 않는다.

### 26.4 데이터 파일 형식, 파일명 규칙 및 버전 관리

### 26.4.1 저장 파일 구조

실험 데이터는 raw, processed, analysis 세 단계로 나누어 저장한다.

| 폴더 | 내용 |
|---|---|
| data/raw | 센서 원본 수신값, 원본 timestamp |
| data/processed | 시간 동기화, 좌표계 변환, 필터링 완료 데이터 |
| data/analysis | 통계 분석에 바로 사용하는 trial-level dataset |
| calibration | IMU bias, hand-eye, base frame, filter parameter 파일 |
| configs | 실험 조건, D-H 파라미터, 제어 gain, preregistration 파일 |
| reports | 실험 결과 표, 그래프, 통계 보고서 |

### 26.4.2 파일 포맷

| 데이터 종류 | 권장 포맷 | 이유 |
|---|---|---|
| raw 시계열 데이터 | Parquet 또는 HDF5 | 대용량 시계열 저장 및 메타데이터 관리에 유리 |
| processed 시계열 데이터 | Parquet | pandas 기반 분석과 호환성 우수 |
| trial-level analysis dataset | CSV + Parquet | 사람이 읽는 용도와 분석용을 병행 |
| 캘리브레이션 파일 | YAML 또는 JSON | 사람이 읽고 버전 관리하기 쉬움 |
| 실험 설정 파일 | YAML | 조건, gain, threshold 관리에 적합 |
| 통계 결과 | CSV + Markdown | 결과표와 해석 동시 저장 |

### 26.4.3 파일명 규칙

각 trial 파일명은 다음 형식을 따른다.

trial_{trial_id}_{robot_model}_{condition_id}_{target_id}_rep{repeat_id}_{date}.parquet

예시:

trial_0007_long_C3_T012_rep03_2026-05-01.parquet

캘리브레이션 파일은 다음 형식을 따른다.

calib_{calibration_type}_{version}_{date}.yaml

예시:

calib_imu_bias_v003_2026-05-01.yaml

calib_handeye_v002_2026-05-01.yaml

calib_baseframe_v001_2026-05-01.yaml

### 26.4.4 버전 관리 정책

코드와 설정 파일은 git으로 관리한다. 데이터 파일은 용량이 커질 수 있으므로 DVC 또는 별도 데이터 저장소를 사용한다.

각 trial metadata에는 반드시 다음 버전 정보를 저장한다.

- git_commit_hash
- data_schema_version
- calibration_version
- dh_params_version
- filter_params_version
- fusion_params_version
- preregistration_version

이 정보를 저장해야 나중에 특정 trial이 어떤 코드, 어떤 캘리브레이션, 어떤 파라미터로 생성되었는지 추적할 수 있다.

### 26.5 캘리브레이션 유효성 및 재캘리브레이션 트리거

캘리브레이션은 한 번 수행했다고 영구적으로 유효한 것이 아니다. IMU 재부착, 카본봉 교체, 모터 재조립, Tracker 위치 변경 등이 발생하면 관련 캘리브레이션을 다시 수행해야 한다.

### 26.5.1 캘리브레이션 파일 종류

| 캘리브레이션 파일 | 내용 |
|---|---|
| calib_imu_bias | IMU별 gyro/acc bias |
| calib_imu_alignment | IMU local frame과 link frame 사이의 정렬 행렬 |
| calib_handeye | IMU frame과 Tracker marker frame 사이의 변환 |
| calib_baseframe | world frame과 base frame 사이의 변환 |

## 27. 연구방법 요약

본 연구는 long-stroke형 카본봉 매니퓰레이터에서 엔코더 없이 IMU 배열만으로 링크 변형 형상을 재구성하고 End effector 위치 제어에 활용할 수 있는지를 검증하는 연구이다. 이를 위해 각 카본봉 링크에 IMU를 3개씩 배치한다. IMU는 링크 시작단, 중앙부, 끝단에 장착되며, 이들로부터 얻은 자세 정보를 이용해 링크의 deformed centerline을 재구성한다.

본 연구의 로봇 플랫폼은 ST3215 모터와 카본봉 링크로 구성되며, 장신형과 단신형 두 모델을 사용한다. 장신형은 A = 233 mm, B = 215 mm, C = 106 mm이고, 단신형은 A = 183 mm, B = 165 mm, C = 56 mm이다. 설계도 기준으로 D-H/FK에 사용되는 모터축 간 유효 링크 길이는 1번 팔 L_A = A + 66.5 mm, 2번 팔 L_B = B + 84.5 mm, 손목부 L_C = C + 44.3 mm로 정의한다. 이에 따라 장신형의 유효 링크 길이는 L_A = 299.5 mm, L_B = 299.5 mm, L_C = 150.3 mm이고, 단신형의 유효 링크 길이는 L_A = 249.5 mm, L_B = 249.5 mm, L_C = 100.3 mm이다. 두 모델은 팔 길이에 따른 처짐 효과를 분리하기 위한 조건이며, 장신형은 더 큰 작업 반경과 더 큰 처짐이 예상되는 조건으로 설정한다.

본 연구의 핵심 비교 조건은 No correction, Encoder only, IMU array only, Encoder + IMU fusion이다. Encoder only는 처짐을 무시한 nominal rigid-body baseline이며, IMU array only는 본 연구의 제안 방법이다. Encoder + IMU fusion은 엔코더 기반 관절각과 IMU 기반 형상 재구성 정보를 결합한 조건이다.

저가형 IMU는 MPU6050을 사용한다. MPU6050 조건은 raw 기반 자세 추정, Kalman filter, Madgwick filter 조건으로 구분하여 비교한다. WT901C는 실시간 자세 데이터 수집이 용이한 상위 IMU 조건으로 사용하며, MPU6050 기반 조건과 비교하여 센서 등급과 출력 안정성이 형상 재구성 및 제어 성능에 미치는 영향을 분석한다.

종속변인은 End effector 최종 위치 RMSE, 축별 오차, bias 성분, 형상 재구성 RMSE, 정착시간, 과도구간 RMS 오차, 잔류 진동 RMS이다. 특히 본 연구는 IMU array가 실제로 링크 형상을 잘 재구성하는지를 검증하기 위해, Tracker로 측정한 링크 지점 좌표와 IMU 기반 재구성 좌표를 비교한다.

제어기와 보정 산식은 모든 조건에서 동일하게 유지한다. 조건 간 차이는 위치 또는 형상 추정에 사용되는 센서 정보와 신호처리 방식에 둔다. Tracker는 제어 피드백에 사용하지 않고, ground truth 평가에만 사용한다.

최종적으로 본 연구는 long-stroke형 처짐 매니퓰레이터에서 엔코더 기반 nominal FK의 한계를 확인하고, 링크별 3점 IMU 배열 기반 형상 재구성이 엔코더 없이도 End effector 위치 추정 및 제어에 활용될 수 있는지를 실험적으로 검증한다.
