# Data Contract

## File Naming

Trial stem:

```text
trial_{trial_id}_{robot_model}_{condition_id}_{target_id}_rep{repeat_id}_{date}
```

Example:

```text
trial_0001_long_C2_imu_array_only_T001_rep01_2026-05-01
```

## Metadata JSON

Required keys:

- `trial_id`
- `condition_id`
- `robot_model`
- `target_id`
- `repeat_id`
- `date`
- `calibration_versions`
- `filter_params_id`
- `fusion_params_id`
- `quality_thresholds`

## Processed CSV Required Columns

- `loop_index`
- `t_common_s`
- `P_hat_encoder_base_mm_x/y/z`
- `P_hat_imu_base_mm_x/y/z`
- `P_hat_fusion_base_mm_x/y/z`
- `P_actual_base_mm_x/y/z`
- `q_imu_world_w/x/y/z`
- `q_encoder_rad_1/2/3`
- `latency_encoder_s`
- `latency_imu_s`
- `latency_tracker_s`
- `quality_flags`

## Trial Plan CSV Columns

Generated by `research_host.cli.generate_trial_plan`:

- `planned_order_index`
- `block_id`
- `condition_id`
- `robot_model`
- `target_id`
- `repeat_id`
- `randomization_seed`

The paired metadata JSON must include `plan_digest_sha256`,
`randomization_seed`, `trial_count`, and `validation_issues`.

## Optimization Candidate CSV Columns

Input to `research_host.cli.optimize_params`:

- Required: `candidate_id`
- Required: `split_id`
- Metric columns use the same names as analysis CSV, for example
  `position_rmse_mm`, `shape_rmse_mm`, `settling_time_s`,
  `residual_vibration_rms_mm`, and `dropped_sample_ratio`.
- Parameter columns must start with `param_`, for example
  `param_base_damping`.

The CLI rejects candidates when `split_id` is not the configured validation
split.

## Simulator Replay Contract

- `q_encoder_rad_1`, `q_encoder_rad_2`, and `q_encoder_rad_3` map to
  `joint_1`, `joint_2`, and `joint_3`.
- Replay timestamps come from `t_common_s`.
- Simulator assets use meters while processed research CSV positions remain in
  millimeters.
- Replay CLIs must support a dependency-free `--dry-run` mode.

## Units

- Time: seconds, suffix `_s`
- Position: millimeters, suffix `_mm`
- Angle: radians, suffix `_rad`
- Quaternion: scalar-first `w, x, y, z`

## Data Storage Policy

- Keep source code, configs, calibration templates, and small samples in git.
- Do not commit real raw/processed/analysis experiment data.
- If data becomes too large for CSV, add Parquet as an optional export without changing the CSV + JSON contract.
