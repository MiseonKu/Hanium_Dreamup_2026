# Hanium Dreamup 2026

SO-101 로봇에 IMU를 추가하여 데이터를 수집하고, 머신러닝으로 말단 위치를 추정한 뒤 위치 보정 가능성을 확인하는 한이음 프로젝트입니다.

## 프로젝트 흐름

`초기 연구 → FK/IK 및 실험점 설계 → 데이터 수집 → 수집 코드 → ML 학습 → 위치 추정 및 보정`

## 폴더 구성

| 폴더 | 내용 |
|---|---|
| `01_Initial_Research_Archive/` | 초기 연구계획, 실험 설계, 오프라인 프로토타입 |
| `02_FK_IK/` | 유연 링크 FK/IK, 작업공간 표본 및 실험 목표점 설계 |
| `03_Dataset_Collection/` | IMU·엔코더·Vive Tracker로 수집한 데이터셋 |
| `04_Data_Acquisition_Code/` | 실제 실험 데이터 수집 코드 |
| `05_ML/` | 머신러닝 모델 학습·평가 및 결과 |
| `06_Position_Estimation/` | 학습 모델을 이용한 위치 추정과 보정 계산 데모코드 |

각 폴더의 자세한 내용은 해당 폴더의 `README.md`를 확인합니다.
