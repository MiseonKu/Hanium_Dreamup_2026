# AGENTS.md

이 폴더는 IMU 추가 실험의 원본 및 파생 데이터 아카이브를 보관한다.

- ZIP 파일을 수정하거나 같은 이름으로 덮어쓰지 않는다.
- 데이터 수집은 `../04_Data_Acquisition_Code/`에서 수행한다.
- 데이터 정제와 ML 학습은 `../05_ML/`에서 수행한다.
- Vive Tracker 위치는 정답값과 평가에만 사용한다.
- 이 폴더에서 모터 제어, 펌웨어 업로드, 센서 수집 또는 ML 학습을 실행하지 않는다.
- 파일을 이동하거나 삭제할 때는 크기와 SHA-256을 먼저 확인한다.
