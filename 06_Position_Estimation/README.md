# 엔코더·IMU 기반 위치 추정 및 보정 데모

기존 ML 모델로 로봇 말단의 현재 위치를 추정하고, 목표 위치와의 차이를 계산한 뒤 관절 명령을 다시 계산하여 한 번 보정 이동하는 데모입니다.

## 데모 동작 순서

1. 기존 실험에서 선정한 5개 목표 중 하나로 이동
2. 정지 상태에서 약 3초간 엔코더와 IMU 데이터 수집
3. 수집값을 43개의 ML 입력 특징으로 변환
4. 기존 ML 모델로 현재 말단의 XYZ 위치 추정
5. 목표 기준 위치와 현재 추정 위치의 차이 계산
6. IK로 관절별 보정 tick 계산
7. 계산된 위치로 한 번 보정 이동한 후 다음 목표로 진행

보정 후 위치를 다시 측정하는 반복 제어 방식은 아닙니다.

## 주요 구성

| 구성 | 역할 |
|---|---|
| 기존 ML 모델 | 엔코더와 IMU를 이용해 현재 말단 위치 추정 |
| 근사 FK | 관절값으로 목표 기준 위치와 이동 방향 계산 |
| IK | 필요한 위치 변화에 맞는 관절별 motor tick 계산 |
| PC | 센서 집계, 위치 추정, 보정 계산 및 명령 전송 |
| ESP32 | 모터 구동과 엔코더 응답 처리 |

기존 3축 모터 ID `1`, `2`, `4`를 사용합니다.

## ML 모델 입력

| 입력 | 개수 | 처리 방식 |
|---|---:|---|
| 엔코더 각도 차이 | 3 | 기준 tick과 현재 tick의 차이를 rad로 변환 |
| IMU 자세각 | 24 | IMU 4개 × XYZ 각도의 sin/cos |
| IMU 가속도 | 12 | IMU 4개 × XYZ 평균값 |
| IMU 각속도 | 4 | IMU별 각속도 벡터 크기의 RMS |
| 합계 | 43 | 학습 당시 특징 순서와 단위 유지 |

Vive Tracker 위치는 모델 학습의 정답값으로 사용됐으며, 현재 데모 실행 중에는 실시간 제어 입력으로 사용하지 않습니다.

## 목표 지점

기존 실험 목표 중 관절 범위, 계산 가능 여부, 데이터 유무와 공간 분포를 기준으로 다음 5개 지점을 사용합니다.

| 목표 | Pan | Lift | Wrist |
|---|---:|---:|---:|
| T002 | 2047 | 2122 | 2714 |
| T032 | 2698 | 2531 | 2425 |
| T034 | 1399 | 2491 | 2382 |
| T015 | 1782 | 2674 | 2148 |
| T044 | 2618 | 2133 | 2172 |

## 위치 보정 계산

```text
목표 기준 위치 = 좌표 변환(근사 FK(목표 motor tick))
현재 추정 위치 = ML 모델(엔코더·IMU 특징값)
보정 요청 벡터 = 목표 기준 위치 - 현재 추정 위치
```

IK는 보정 요청 벡터를 실제 관절별 motor tick으로 변환합니다. 이 계산은 모터를 움직이기 전에 PC에서 수행됩니다.
